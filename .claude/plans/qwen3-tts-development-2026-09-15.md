# Qwen3 TTS 개발

설계 후 사용자의 “개발 진행해줘” 요청에 따라 로컬 개발·설치·실제 합성 검증까지 진행한다.

1. 공통 설정·저장·실행 계약 확정.
2. 독립 Python 환경과 Qwen 상주 서비스·큐·캐시 구현.
3. 웹 음성 스튜디오·미리듣기·참조 업로드·프리셋 API 구현.
4. A/B 회차 적용과 음성 재생성·타이밍·오래된 결과 판정 연결.
5. 타입 검사·회귀 테스트·실제 GPU 음성 생성·브라우저 검증.

G1–G5 PASS. 아키텍처와 최종 리뷰에만 powerful 하드 오버라이드 적용. 모든 작업은 메인 직접 수행한다. 사용자가 작업 중인 파일 변경을 보존한다. 자동 게시나 유료 영상 재생성은 개발 검증에 포함하지 않는다.

설계의 Python 3.12 권장값은 장비에 설치된 Python 3.10 독립 venv로 조정한다. 공식 qwen-tts 0.1.1은 Python >=3.9를 지원한다.

개발 완료: D1–D5 구현 및 검증. CustomVoice 0.6B·1.7B, VoiceDesign 1.7B, Base 0.6B의 실제 한국어 생성과 웹 재생·프리셋 저장·B안 실제 오디오 연결을 확인했다. 기본 테스트 77개, 서비스 API 5개 및 11개 하위 검사가 통과했다. 상세 결과와 현재 구현 한계는 `pipeline/tts-service/VALIDATION.md`에 기록했다.
