- 산출물: `docs/설계/03-Qwen3-TTS-음성스튜디오.md`, 대화형 화면 시안.
- 범위: 화면 흐름, 기능별 모델 선택, 프리셋·참조 음성·미리듣기 데이터, API 계약, 기존 A/B 트랙 연동과 후속 구현 순서.

- 배정: 아키텍처와 최종 리뷰 모두 메인 직접 수행. 실제 모델 전환 또는 위임을 하지 않음.

- G2 PASS: 아키텍처·모호한 요구·최종 리뷰 하드 오버라이드 적용.
- G3 PASS: frontend / review 도메인의 허용 범위 준수.
- G4 PASS: powerful 100%의 이유를 두 노드별로 명시.
- G5 PASS: 설계 파일 작성만 진행하며 모델 설치·실제 합성·외부 공개 없음.
