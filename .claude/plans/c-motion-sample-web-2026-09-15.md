# C안 샘플 영상·웹 페이지 구현

사용자의 후속 요청으로 C안 설계 작업을 12초 샘플 렌더와 웹 콘솔 페이지 구현까지 확장했다.

G1~G5 PASS. powerful 노드는 영상 레이어 구조를 결정하는 S3과 최종 검토 S7이며 전체 7개 중 2개다. 외부 게시나 업로드는 포함하지 않는다.

## 완료 결과

- 지도 확대, 항로, 섬 배경, 인물 등장, 한국어 TTS가 포함된 1080×1920·60fps·12.053초 MP4를 렌더했다.
- 웹 콘솔에 `/c-motion` 정적 페이지와 내비게이션을 추가했다. 컷 선택 시 영상이 해당 시점으로 이동하고 대본이 바뀐다.
- Remotion과 웹 TypeScript 검사, Next.js 운영 빌드, 실제 브라우저의 MP4 메타데이터·상호작용·390px 반응형을 검증했다.
- 기존 동적 파일 접근에 관한 Turbopack 경고 8개는 남아 있으며 이번 변경의 오류는 아니다.
