# 표정·흐름·부작 표기 수정 완료

## 반영 내용

- 1/3의 10장을 내장 image_gen으로 다시 제작했다. 승인된 그림체와 캐릭터 외형은 참조로 유지하고, 기쁨·실망·상처·당황·억울함·낙담·의심의 얼굴 연기를 구분했다.
- 친구 셋 소개, 약속 시간과 한 시간 대기, 집에 돌아온 뒤 상담, 수진의 핀잔, 그날 밤 개인 부탁 순서로 진행한다. 회사 앞 케이크집과 수진의 늦은 퇴근을 넣어 부탁의 이유를 설명했다.
- 이 사연은 3부로 구성하되, 기획 규칙에서 3부 고정을 해제했다. 2/3과 3/3 콘티도 원인과 결과가 이어지도록 다시 썼다.
- 첫 장은 1/3, 마지막 장은 -계속-. 1화 및 다음 부작 제목 예고와 장수 표기는 제거했다. 3/3 콘티는 -끝-으로 마무리한다.
- 생성 중 잘못 들어간 남친 대화방/친구 단톡방 이름, 불필요한 제목 반복과 추가 생각 문구, 사진풍 꽃다발을 다시 수정했다.

## bkit 적용 단계

- Plan: 사용자 피드백 세 가지를 성공 조건으로 정리.
- Design: 시간순 3부 콘티, 장면별 표정, 표지·끝표기를 정의.
- Do: 이미지 재생성, 작업실 버전 기록과 기존 컷 편집기 연결 유지. 자동 생성 규칙과 향후 승인 제목 표기도 최신 문구로 수정.
- Check: TypeScript 검사, 10장 전체 렌더와 1080×1350 확인, 편집기 DOM 확인, 생성 이미지 전체 시각 확인, 기존 버전 기록 보존 검사.

## 파일

- 최신 콘티: 한술툰/기획/첫사연-친구-단톡방-콘티-03.md 및 JSON
- 그림: 컷/01-수정02.png ~ 컷/10-수정02.png
- 게시용: 출력/01.jpg ~ 출력/10.jpg 및 캡션.txt
- 압축본: 한술툰-1부-수정02-게시용.zip
- 최종 프롬프트 및 생성 원본 경로: 이미지생성-수정02-기록.json
- 검증 결과: 수정02-검증.json
- 이전 출력: 이전출력-01. 이전 그림·ZIP·콘티·작업실 버전은 보관했다.
