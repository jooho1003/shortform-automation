# 한술툰 1화 그림 제작 및 편집기 연결

## 요약

- 요청: 1화 캐릭터와 10장 전체 작화, 어울리는 배경·말풍선·글씨.
- 원인: 콘티 승인 단계는 텍스트와 기본 캐릭터 경로만 전달했고 이미지 생성은 실행되지 않았다. 캐릭터 영역도 시트 경로만 보여 주고 있었다.
- 결과 목표: 본편 10장과 보리·수진·미소 시트를 실제 이미지로 연결하고, 편집기 미리보기와 게시용 출력에서 글씨 중복과 잘림을 없앤다.

## Plan · 범위

- 내장 image_gen으로 05 캐릭터 기준에 맞는 3인 공동 시트와 본편 10장을 만든다.
- 원래 콘티·대사는 `그림생성전-프로젝트.json`에 보존한다. 생성 지시와 원본 이미지 위치는 `이미지생성-기록.json`에 기록한다.
- 참고 게시물: https://www.instagram.com/p/Dd2UFOmHyek/?img_index=2
- 폰트명은 확정하지 않았다. 실제 화면의 둥근 손글씨, 갈색 선과 옅은 말풍선 색을 참고한 이미지 내 레터링이다.

## Design · 최소 변경

- 단일 컷에 `fullBleed`를 선택적으로 저장한다. 완성 페이지에만 적용하며 기본 컷 방식은 유지한다.
- 완성 페이지는 별도 테두리·푸터 없이 전체를 contain으로 표시한다. 이미지 속 말풍선과 겹치는 기존 오버레이는 보관본에 남긴다.
- 광고 표기는 완성 이미지 방식에서도 유지한다.
- 캐릭터 영역에 실제 시트 미리보기를 표시한다. 같은 공동 시트는 한 번만 보여 준다.
- 편집기에 손글씨가 이미지에 포함되어 있다는 점과 수정 시 재생성이 필요하다는 점을 명시한다.

## Check · 검증 기준

- TypeScript 검사 통과.
- 10장 모두 대사·화자·번호 시각 확인, 기준 시트의 캐릭터 색과 외형 유지.
- 편집기에서 10장 미리보기와 공동 캐릭터 시트 정상 로드.
- 서버 저장 후 fullBleed 유지, 대사 오버레이 중복 없음.
- 게시용 출력 10개, 각각 1080×1350, Instagram 게시 전 로컬 검토 상태.

## 수정 방법

- 이야기의 수정 원본은 한술툰 작업실의 1화 콘티와 생성 전 프로젝트 보관본이다.
- 현재 이미지 안의 글씨는 독립된 폰트 레이어가 아니다. 수정 대사를 반영해 해당 이미지를 다시 생성·교체해야 한다.
- 컷 편집기의 추가 말풍선은 새 오버레이를 추가하는 기능이며, 그림 속 글씨를 지우거나 바꾸지는 않는다.

## 검증 결과

- npm run typecheck: 통과.
- Remotion 전체 10장 렌더: 성공.
- 출력 01.jpg~10.jpg: 모두 1080×1350 확인.
- 컷 편집기 DOM: 완성 이미지 10장, 공동 캐릭터 시트, 원본 링크 및 수정 안내 확인.
- 저장 API: fullBleed 10장 유지, 캐릭터 3명, lint 오류·경고 없음.
- 생성 결과 10장을 시각 확인했고, 실제 렌더된 표지에서 전체 구도와 글씨·푸터 중복 없음 확인.
- Aside 전체 화면 스크린샷은 타임아웃되어, DOM 확인과 동일 컴포넌트의 실제 렌더 출력 확인으로 검증했다.
