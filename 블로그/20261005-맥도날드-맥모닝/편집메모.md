# 맥모닝 초안 편집 메모

- 사용자 제공 방문 경험과 맥모닝 폴더의 HEIC 4장만 근거로 작성.
- 베이컨 토마토 에그 머핀 세트 2개, 아이스커피 라지 2잔, 코울슬로 1개, 해시브라운 1개, 베이컨 에그 맥머핀 단품 1개, 핫케이크 2피스로 주문 구성 정리.
- 공휴일 방문과 진주 고추 크림치즈 머핀 품절은 사용자 방문 경험으로만 기록. 현재 판매·전 매장 재고 안내로 확장하지 않음.
- 사용자의 표현인 고모씨, 이모씨, 푸데잠 유지.
- 평점 분류는 햄버거, 점수는 2.8 / 5. 별 아이콘은 반올림하지 않고 카드에 숫자로만 표시.
- 결제 방식과 전체 결제액 미확인. 내돈내산 또는 합계 가격을 원고에 추가하지 않음.
- 사용자가 방문 지점을 맥도날드 상일동점으로 확인. 주소는 서울 강동구 상일로6길 39, 강동타워 1층. 매장 제공 채용 공고(https://www.alba.co.kr/job/Detail?adid=147099108)와 다이닝코드(https://www.diningcode.com/profile.php?rid=ItovaSiycddu) 주소 교차 확인. 평점 다음에 주소·해당 지점 지도 검색 링크 추가, 지도 링크가 마지막. 네이버 편집 시 해당 지점 장소 카드로 교체.
- 원고 승인 전 상태. 네이버에 옮기거나 발행하지 않음.
- 네이버 서식은 본문 바른히피 15px·가운데 정렬·행간 1.8, 소제목 다시시작해 15~16px·연두 형광펜, 핵심 맛 표현은 살구·이용 팁은 하늘 형광펜을 절제해서 적용. 로컬 승인 페이지는 네이버 서식을 완전히 재현하지 않음.
- 본문 맨 위에 왼쪽 세로선(`|`) 요약 인용 3줄을 추가. Markdown `>` 문법을 사용하며 네이버에서는 세로선 인용구로 적용.
- 리트리버는 음식 사진 옆에서 제거하고 사진 없는 식사 후 일상 이야기 구간의 전환으로 이동. 폭 약 220px·가운데 정렬, 앞뒤 사진과 내용 있는 본문 문단으로 분리. 인물은 총평 다음 마지막 평점 카드에만 사용.
