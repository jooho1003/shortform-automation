## 실제 관찰한 서식과 문맥

- 머리 요약: 왼쪽 세로선이 있는 인용구(`se-l-quotation_line`). 나눔고딕 19px, 회색 `#666666`, 왼쪽 정렬, 3줄. 글 제목과 별도다.
- 본문: 바른히피(`se-nanumbareunhipi`) 15px, 검정, 가운데 정렬. 의미 단위로 줄을 나누고 문단 사이를 비운다. 확인한 본문 글자 행간은 27px(1.8배). 빈 문단·태그·캡션에 보이는 13px를 본문 기본값으로 오인하지 않는다.
- 소제목·전환: 다시시작해(`se-nanumdasisijaghae`) 15px와 연두 배경을 주로 사용한다. 크기보다 서체·색으로 구분하며 모든 사진 묶음에 독립된 소제목이 있는 것은 아니다.
- 형광펜: 연두 `#e3fdc8`, 노랑 `#fff593`, 살구 `#ffd1a4`, 하늘 `#b0f1ff`. 문단 전체 박스가 아닌 글자 뒤 배경이다. 연두는 도입·전환에 반복되고 나머지는 문장·문단 단위로 교대한다. 원본의 색별 의미가 엄격하게 고정됐다고 단정하지 않는다.
- 강조: 확인한 본문 span은 굵기 400, 밑줄 없음. 문단 상당수에 형광펜을 쓰며 굵게보다 서체·배경색·빈 줄이 구분을 만든다.
- 구분선: 네이버 기본 가로선(`se-l-line1`), 1px 연회색 `#dddddd`. 사진·설명 한 묶음이 끝나고 주제가 바뀌는 곳에 앞뒤 여백을 두고 배치한다.
- 문맥: 방문 계기 → 눈으로 본 모습 → 먹는 과정 → 개인 판단. 곁들임·소스를 바꿔 먹는 순서로 다음 문단을 연결한다. 방문형은 후반 이용 정보·팁, 배달 메뉴형은 비교·먹는 법·가격으로 달라진다.

## 우리 블로그 적용표

색의 역할과 강조량은 관찰을 바탕으로 정한 우리 편집 기준이다. 원본의 공식 규칙이 아니다. 차분한 1인칭 해요체, 실제 경험만 쓰기, 리트리버·평점 카드, 지도 마지막 규칙을 함께 적용한다.

| 요소 | 기본값 |
| --- | --- |
| 첫머리 | 가게·메뉴·핵심 감상을 담은 2~3줄 요약 인용 한 번. 짧은 글에서 도입과 중복되면 생략. 제목 전체·총평을 반복하지 않는다. |
| 본문 | 바른히피 15px, 검정, 가운데 정렬, 행간 약 1.8. 모바일에서 작으면 16px. 폰트가 없으면 나눔고딕으로 대체하고 확인한다. |
| 소제목 | 다시시작해 15~16px, 연두 `#e3fdc8`. 필요할 때 이모지 한 개. 폰트가 없으면 본문 폰트와 연두 강조로 구분한다. |
| 요약 인용 | 나눔고딕 19px, 회색 `#666666`, 왼쪽 세로선·왼쪽 정렬. 전체 가운데 정렬 후에도 이 블록은 왼쪽 정렬로 복구한다. |
| 형광펜 | 연두=소제목·전환, 노랑 `#fff593`=메뉴·가격·핵심 사실, 살구 `#ffd1a4`=맛·감상, 하늘 `#b0f1ff`=비교·이용 팁. 확인된 내용에만 쓴다. |
| 강조량 | 문단마다 핵심 구절 또는 한 문장까지만 칠하고 나머지는 기본 글씨. 짧은 글은 연두·노랑만으로 충분하다. 색을 채우려고 문장을 만들지 않는다. |
| 굵게 | 메뉴명·핵심 결론의 짧은 구절에만 보조적으로 사용. 형광펜·밑줄과 같은 구절에 중첩하지 않는다. 원고의 굵게를 형광펜으로 옮기면 굵게를 해제해도 된다. |
| 구분선 | 큰 주제 전환에 기본 가로선 한 종류만 사용. 우리 분량은 보통 2~4개, 짧으면 더 적게. 사진마다 반복하거나 문자 기호를 길게 나열하지 않는다. |
| 여백 | 문단은 1~3문장, 사진·문단·구분선 사이 한 줄 여백. 의미 단위로 끊되 단어 중간을 강제로 나누지 않는다. |

구성: `요약 인용(선택) → 도입 → 공간·메뉴와 사진 → 리트리버·맛 후기 → 확인된 이용 팁(있을 때) → 총평 → 인물 평점 카드·문구 → 주소 → 네이버 지도`.

메뉴 비교·먹는 순서는 실제 경험이 있을 때만 쓴다. 원본의 반말체, 반복적인 검색어·총평, 지도 뒤 문장·스티커 배치는 가져오지 않는다.

## 원고와 네이버 편집 연결

- 개요·초안·윤문은 공통 `pipeline/prompts/blog/style.md`를 읽는다. 원고에는 인용(`>`), 소제목(`##`·`###`), 짧은 굵게(`**…**`), 빈 줄로 구조와 강조 후보를 남긴다.
- 폰트·정렬·형광펜·네이버 기본 구분선은 Markdown만으로 보존되지 않는다. 네이버 편집 단계에서 적용표를 따른다. 본문에 색 이름, CSS, HTML, `[형광펜]` 같은 편집 지시를 노출하지 않는다.
- 기존 로컬 승인 페이지에서 원고·사진을 검토한다. 재현되지 않는 네이버 전용 서식은 별도 편집 메모에 남긴다. 텍스트 미리보기만 보고 실제 서식 적용이 끝났다고 판단하지 않는다.
- 네이버 발행 전후 실제 화면에서 폰트·정렬·강조량·구분선·여백을 확인한다. 작은 리트리버, 마지막 평점 카드, 지도 최하단도 확인한다.
- 이번 작업은 앞으로 쓸 작성·편집 기준 저장이다. 기존 게시물 일괄 수정이나 승인 페이지 렌더러의 자동 서식 기능 구현을 뜻하지 않는다.
