# 사진·원고 준비 기록

- 사용자가 제공한 실제 방문 경험으로 작성. 내돈내산·단골집·개인 평점 4.8점 확인.
- 사용자 원본 HEIC 5장은 원본 폴더에 보존. converted는 화질 보정 없이 JPEG로 포맷 변환한 파일.
- 사진 편집은 내장 imagegen 사용. 음식·현장 구도를 유지하도록 요청하고 출력과 원본을 시각 비교했으나, 생성형 편집이므로 픽셀·세부 질감이 재생성될 수 있다. 엄밀한 원본 픽셀 보존 보정으로 표현하지 않는다.
- 최종 보정 사진 5장, 새 투명 리트리버, 숫자 4.8 / 5 인물 평점 카드 1장.
- 평점의 반올림·잘못된 반쪽 별을 피하기 위해 최종 평점 카드는 숫자만 표시한다.

## 조건 없는 외부 사진 검색

사용자가 '조건없는거로 찾아봐줘'라고 확정. 2026-10-02 확인.

- Wikimedia Commons와 Openverse에서 Jinmi Namyangju 검색: 결과 0. Openverse는 cc0,pdm 라이선스 필터 사용.
- CC0, 퍼블릭 도메인, 무료 이미지, 조건 없는 재사용, Pixabay/Pexels/Unsplash를 조합한 매장명 검색: 해당 매장의 사진을 확인하지 못함.
- 한국관광공사 소개 사진에도 외부 네이버 블로거 저작권이 표시되어 있어 조건 없는 사진으로 사용할 수 없음.
- https://mokeya.tistory.com/831 의 하우스·메뉴판 사진은 CC BY-NC-ND 4.0. 사용자가 조건 없는 자료를 원하므로 최종 이미지 목록과 본문에서 제외.
- 위 자료는 확인 목적으로 브라우저의 artifacts/jinmi-research에 원본을 받았으나 게시용 이미지로 넣지 않았다.
- 실제 가게나 메뉴판을 AI로 재현하지 않았다. 가격은 네이버 플레이스의 텍스트 메뉴 정보로 확인해 표로 추가했다.

## 영업시간과 위치

- Google 매장 카드에는 11:00~22:00, 공식 매장 계정 https://www.instagram.com/khk5292/ 에는 11:00~20:30·화요일 휴무 표시. 공식 계정 표시를 본문에 출처와 함께 기록.
- 주말 조기 마감 시각은 사용자의 방문 경험이며 상시 마감 규칙으로 단정하지 않는다.
- 주소는 공식 매장 계정과 한국관광공사 https://japanese.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=249219 에서 일치 확인.
- 발행 카테고리: 맛집. 개인 평점 카테고리: 고기·구이.
- 지도 검색 링크는 맨 마지막. 네이버로 옮길 때 정확한 주소의 장소 카드로 교체하고 지도 뒤에 아무것도 넣지 않는다.
