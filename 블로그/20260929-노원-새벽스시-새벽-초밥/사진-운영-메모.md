# 새벽스시 사진 운영 메모

## 이번 글

- 대표: 직접 촬영한 회전 레일 사진 `이미지/00-대표-보정.jpg`.
- 본문 1: 직접 촬영하고 먹은 롤 사진 `이미지/01-보정.jpg`.
- 본문 2: 직접 촬영한 초밥 선택지 사진 `이미지/02-보정.jpg`.
- 원본 4장은 `숏폼/블로그/새벽스시/`에 그대로 둔다. 다른 손님 얼굴이 보이는 넓은 실내 사진은 이번 글에서 제외한다.
- 게시용 사진은 원본 사본을 `ffmpeg`로 회전·구도·밝기만 조정했다. 음식과 매장 디테일이 달라진 AI 보정 시도는 채택하지 않았다.

## 다음 방문부터 사진 늘리는 방법

1. 매장 밖에서 상호가 보이는 입구 1장, 실내 전경 1장, 메뉴판 1장, 주문한 음식마다 근접 사진 1장을 직접 찍는다. 다른 손님 얼굴은 프레임에서 뺀다.
2. 네이버 지도·카카오맵·다른 리뷰의 사진은 장소와 메뉴 확인용으로만 살펴본다. 사진을 저장해 내 글에 재게시하려면 촬영자 또는 권리자의 사용 허락을 먼저 확인하고 출처와 허락 내역을 기록한다.
3. 매장이 직접 제공한 사진도 블로그 재게시 허락을 확인한 뒤 사용하고, 직접 찍은 사진과 구분해 표시한다. 허락받은 사진이 없으면 장소 링크를 걸고 외관 설명은 생략한다.
4. 밝기·색감 보정 후에는 원본과 음식, 메뉴판, 가격, 공간 구조가 일치하는지 비교한다. 달라진 결과는 게시하지 않는다.

이 글에는 외부에서 가져온 사진이 없다.
