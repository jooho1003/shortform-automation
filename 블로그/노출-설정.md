# 그날의 먹거리 검색·추천 설정

점검일: 2026-10-02. 사용자의 요청에 따라 Aside에서 네이버 관리자 및 발행 패널을 직접 확인했다.

## 적용 사항

- 블로그 대표 주제는 기존 `맛집`을 확인했다.
- 소개를 `직접 다녀온 서울·경기 맛집과 카페를 기록합니다. 먹어본 메뉴의 맛과 가격, 분위기, 방문 팁을 사진과 함께 솔직하게 남겨요.`로 변경하고 관리자 재조회 및 공개 프로필에서 저장을 확인했다.
- `일식·초밥`, `한식·국밥`, `고기·술집`, `카페·디저트`, `그 밖의 한 끼`의 카테고리 주제를 `맛집`으로 저장했다. 관리자 페이지를 다시 열어 5개 모두 확인했다.
- 진미오리 발행 패널에서 기존 전체공개·검색허용 상태를 확인하고 `이 설정을 기본값으로 유지`를 선택해 저장했다. 댓글·공감·링크 공유·외부 공유도 기존 허용 상태로 저장됐다.
- 카테고리 주제는 기존 게시글에 소급되지 않아 기존 음식 후기의 개별 주제도 별도로 점검했다. 글별 결과는 아래에 기록한다.
- 앞으로 발행할 때 개별 글의 주제·공개·검색허용을 확인하도록 `AGENTS.md`, `맛집-글쓰기-설계.md`, `pipeline/prompts/blog/style.md`에 반영했다.

## 앞으로의 작성·발행 기준

1. 제목은 기존 기준인 `지역 + 가게명 + 실제 방문 경험 한 가지`를 유지한다. 본문에 없는 키워드를 추가하거나 같은 단어의 반복 횟수를 채우지 않는다.
2. 직접 찍은 사진과 직접 겪은 맛·분위기·방문 팁을 중심으로 작성한다. 가격·영업시간은 확인한 정보와 사용자 경험을 구분한다.
3. 발행 패널에서 해당 카테고리와 개별 주제 `맛집`, 전체공개·검색허용을 매번 확인한다.
4. 태그는 지역·가게·실제 메뉴 등 관련 항목만 사용한다. 태그 최대 개수를 채우는 것을 목표로 하지 않는다.
5. 정확한 지점의 네이버 장소 카드를 본문 마지막에 넣는다. 플레이스 리뷰 수집 여부·순위는 직접 지정할 수 없다.
6. 발행 후 통계의 검색 유입어와 실제 읽힌 글을 참고해 다음 후기의 정보를 보완한다. 클릭·공감·이웃을 인위적으로 늘리는 방식을 사용하지 않는다.

## 네이버 공식 근거

- [검색 노출 설정](https://help.naver.com/service/5593/contents/15555?osType=COMMONOS): 게시글 공개와 검색허용을 점검하는 근거.
- [주제별 블로그 선정](https://help.naver.com/service/5593/contents/15192?lang=ko&osType=COMMONOS): 개별 글의 적합한 주제 분류는 주제별 추천 대상 선정에 도움이 된다. 검색 순위 상승을 보장한다는 뜻은 아니다.
- [블로그 웹검색과 소개](https://help.naver.com/service/30010/contents/17675?lang=ko&osType=PC): 네이버 블로그는 별도 웹검색 등록이 필요하지 않으며 제목·소개가 검색 설명에 사용된다. 소개 수정 반영은 약 48시간, 검색 주기에 따라 더 걸릴 수 있다.
- [D.I.A. 안내](https://help.naver.com/service/5626/contents/22926?lang=ko&osType=COMMONOS): 경험·정보성·주제 적합성·독창성·적시성 등을 종합적으로 고려한다.
- [플레이스 블로그 리뷰](https://help.naver.com/service/30026/contents/20489?osType=COMMONOS): 지도 포함 글 중 적합한 글을 자동 수집한다. 반영은 일주일 정도 또는 더 걸릴 수 있다.

이 기록은 설정 적용 결과다. 특정 검색어의 노출·순위·추천 선정은 보장하지 않는다.

## 추가 개선·측정 — 2026-10-02 23시대

사용자의 추가 요청에 따라 검색·추천·플레이스·외부 공유·블로그 내 탐색·통계를 넓혀 점검했다.

### 추가 적용

- 진미오리 제목을 `남양주 진미오리숯불구이, 노상 감성 오리구이와 비빔국수`로 변경했다. 지역·상호·분위기에 실제 메뉴를 더해 글의 내용을 판단하기 쉽게 한 편집적 개선이며, 순위 상승을 입증한 변경은 아니다. 편집기에서 제목 외 본문 텍스트의 변경이 없음을 비교했고, 발행 후 사진 7장·대표 오리구이 사진·지도 유지 및 새 제목을 확인했다. 프로젝트 revision 11 및 로컬·사용자 폴더의 미리보기도 동기화했다. 최초 승인·발행 검증 파일은 당시 기록으로 보존했다.
- 전체보기의 `목록열기`를 기본으로 저장하고 5줄 목록을 유지했다. 관리자 재조회와 공개 블로그에서 4개 후기 링크가 펼쳐진 상태를 확인했다. 목적은 방문자가 다른 후기를 바로 찾도록 하는 것이며 검색 순위 요소로 단정하지 않는다.
- 크리에이터 어드바이저의 검색 트렌드 관심 주제에 `맛집`을 추가했다. 기존 관심 주제 8개도 유지했다. 이는 글감 조사용 개인 설정이며 공개 추천 주제와 별개다.

### 추가 확인

- 4개 글 모두 대표이미지 메타데이터와 정확한 지점의 네이버 장소 카드를 확인했다. 진미오리는 오리구이 사진, 백옥은 돼지곰탕 사진을 대표로 사용한다. 케이찹사라다와 새벽스시도 기존 사진으로 대표이미지가 지정되어 있다.
- 콘텐츠 공유 설정: 자동 출처 사용, CCL 사용안함, 우클릭 금지 사용안함. 기존 설정을 유지했다. CCL 부여는 검색 노출 필수 조건이 아니다.
- 새 제목 발행 시 주제 맛집·전체공개·검색허용을 다시 확인했다.

### 측정 기준값

관리자 일간 현황의 **2026-10-02 23:17 기준** 표시와 같은 날 크리에이터 어드바이저에서 확인했다. 당일 값은 마감 전 잠정치다. 운영자 확인 방문의 포함 여부는 이 점검에서 분리하지 못했으며 방문수·유입수를 노출수나 클릭률로 바꾸어 해석하지 않는다.

### 다음 운영에 적용할 기준

- 새 방문 후기는 `지역·가게 + 실제 메뉴/방문 상황`에 집중하고, 주문 메뉴·가격·방문 시간·장점·아쉬운 점·지도 중 확인 가능한 정보를 빠짐없이 담는다. 영업시간처럼 변하는 정보는 확인 날짜와 근거를 내부 기록에 남긴다.
- 기존 글을 반복 발행하거나 제목만 계속 바꾸지 않는다. 재방문으로 새 정보가 생겼을 때 실제 달라진 내용을 업데이트한다.
- 관련 후기가 충분히 생기면 같은 지역·비슷한 식사 목적의 글을 총평 이전에 연결한다. 현재 4편을 무관한 키워드나 지역으로 억지로 연결하지 않는다.
- 매주 직전 완결된 7일과 그 이전 7일의 검색 유입수·검색어 종류·플레이스 유입·글별 조회수·재방문율을 비교한다. 조회수가 아니라 실제 검색 유입어에서 다음 글의 정보 수요를 찾는다. 일정 예약이나 자동 점검 작업을 생성한 것은 아니다.
