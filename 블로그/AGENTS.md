# 그날의 먹거리 블로그 작성 규칙

## 반드시 읽을 기준

- `맛집-글쓰기-설계.md`: 사용자가 확정한 글쓰기·디자인 기준의 원본.
- `../pipeline/prompts/blog/style.md`: 자동 개요·초안·윤문 단계에서 공유하는 요약.
- `참고-스타일-goodday-tomorrow.md`: 2026-09-30 지정한 참고 블로그의 관찰 근거와 폰트·형광펜·구분선 적용표. 앞으로 글을 작성·편집할 때 함께 읽는다.
- 기존 글의 방문 사실·메뉴·점수는 새 글의 사실로 복사하지 않는다.

## 고정 기준

1. 차분하고 친근한 1인칭 해요체. 확인된 사실 뒤에 개인 감상·해석을 잇는다. `ㅋㅋ`·`ㅎㅎ`, 과장, 정형적인 방문사진·가격 면책 문구는 쓰지 않는다.
2. 사용자가 제공한 실제 사진·맛·방문 경험만 쓴다. 결제 방식·평점·메뉴 등이 없으면 필요한 내용만 묻고 추정하지 않는다. 이번 글의 내돈내산 여부나 3점 평가를 다음 글의 기본값으로 삼지 않는다.
3. 사진과 짧은 문단, 소제목, 절제된 이모지와 여백을 번갈아 배치한다. 맛 후기를 긴 글 덩어리로 두지 않는다.
4. 본문 맛 후기에는 글의 음식에 맞는 새 리트리버 스티커를 만든다. 기존 이미지는 캐릭터의 황금색 털·둥근 얼굴·늘어진 귀·수채화 스타일 참고용이며 그대로 재사용하지 않는다. 이전 글의 음식 소품도 반복하지 않는다. 투명 배경, 폭 약 220px, 가운데 정렬로 쓴다.
5. `assets/그날의-먹거리-프로필.png`의 인물은 마지막 별점 카드에만 사용한다. 인물 맛보기 이미지는 사용하지 않는다. 점수별 카드의 별 개수는 사용자가 준 점수와 일치시킨다.
6. 흐름: 도입 → 공간·메뉴와 실제 사진 → 리트리버·맛 후기 → 총평 → 인물 별점 카드·평점 문구 → 주소 → **네이버 지도 맨 마지막**. 지도 뒤에는 내용이나 이미지를 붙이지 않는다.
7. 평점 문구는 `⭐ 제 [카테고리] 카테고리 평점은 5점 만점에 [점수]점입니다.`로 통일한다.
8. 시각 서식은 goodday_tomorrow 참고 기준을 적용한다. 본문 바른히피 15px·가운데 정렬, 소제목 다시시작해·연두, 요약 인용 나눔고딕 19px·왼쪽 정렬. 연두 `#e3fdc8`·노랑 `#fff593`·살구 `#ffd1a4`·하늘 `#b0f1ff` 형광펜과 얇은 기본 가로선으로 구분한다. 원고의 `---` 구분선은 로컬 미리보기에서 가로선으로 보여주고 네이버 편집기에서는 기본 구분선으로 넣는다. 한 문단에서 핵심 구절 또는 한 문장만 강조한다.

## 작성·승인·발행

- 맛집·카페 방문 후기는 발행 패널에서 개별 글 주제 `맛집`, `전체공개`, `검색허용`을 확인한다. 카테고리 주제만 바꾸면 기존 글에는 소급 적용되지 않으므로 개별 글도 확인한다. 지역·가게·실제 메뉴와 관련된 태그만 쓰고 정확한 지점의 장소 카드를 넣는다. 상세 설정과 공식 근거는 `노출-설정.md`를 참고한다.
- 노출 개선을 점검할 때는 대표사진·제목·장소 연결과 실제 검색 유입어를 함께 확인한다. 제목·본문을 불필요하게 반복 수정하지 않고, 변경 전후 내용 보존과 공개 화면의 저장을 검증한다. 트렌드 검색어만 보고 방문 경험을 만들어내지 않는다. 운영 통계는 같은 기간끼리 비교하고 유입수·조회수를 검색 노출수나 클릭률로 부르지 않는다.
- 발행 카테고리를 반드시 선택하고 로컬 프로젝트와 네이버의 카테고리명을 맞춘다. 현재 케이찹사라다 글은 `카페·디저트`다. 본문에서 말하는 `간식 카테고리 평점`은 개인 평가 분류이며 네이버 게시 카테고리와 구분한다. 발행 후 해당 카테고리 목록에도 글이 보이는지 확인한다.
- 기존 로컬 블로그 승인 페이지에서 사진·본문·장식·평점을 함께 검토할 수 있게 준비한다. 로컬 파일만 만들어 두고 승인 페이지를 생략하지 않는다. 현재 콘솔 기본 주소는 `http://localhost:3123/blog`이며 실행 상태를 확인해 사용한다.
- 새 글은 사용자가 원고를 승인하고 블로그 작성을 요청한 뒤 네이버에 옮긴다. 이미 승인한 글에 대한 명시적인 수정 요청은 해당 수정의 승인으로 보고 진행한다. 같은 승인을 반복 요청하지 않는다.
- 브라우저는 Aside를 기본으로 사용한다. 정확한 지점의 네이버 장소 카드를 선택한다.
- 발행 전후 실제 화면에서 사진 누락·중복, 문장 중간 이미지 삽입, 작은 리트리버 표시, 마지막 인물 평점, 지도 최하단을 확인한다. 로컬 원고·이미지 목록·게시 URL도 맞춘다.
- 사용자 선호가 바뀌면 설계, 이 지침, `style.md` 및 충돌하는 초안·윤문 프롬프트를 함께 수정해 오래된 규칙이 남지 않게 한다.
