# 상세페이지 관리자 디자인 편집 — 2026-09-12

LUMEN 화장품 상세페이지에 관리자 설정 패널을 연결했다. 공개 결과와 동일한 렌더러를 사용하고, 인증된 관리자에게만 편집기를 제공한다.

## 사용 순서

1. `/detail-admin`에서 관리자 키로 로그인한다. 이 PC의 키 파일은 `%USERPROFILE%\AppData\Local\ShortformAutomation\detail-admin-key.txt`다. 키는 프로젝트/미디어 제공 경로 밖에 보관하며 화면·문서에 값을 싣지 않는다.
2. 상세페이지 의뢰서 목록 → 결과 보기 → 상단 **설정**을 누른다.
3. 문구를 직접 클릭하거나 **수정할 문구**에서 고른다. 원문이 입력란에 표시되며, 문구·글꼴·색상·글자 크기를 각각 수정할 수 있다.
4. 전체/제목 폰트와 배경·본문·강조·보조 색상을 바꾼다. 색상표와 HEX 입력을 모두 지원한다.
5. 이미지를 직접 드래그하거나 **수정할 이미지**에서 고른 후 가로·세로·확대 슬라이더로 조절한다.
6. **저장** 후 **출력 화면 (마지막 저장본)**을 연다. 저장하지 않은 변경은 출력 링크에 반영되지 않는다.

**되돌리기**는 마지막 저장 상태로, **원문 복원**은 의뢰서/템플릿의 문구로, **스타일 초기화**는 해당 문구의 기본 스타일로 돌아간다. 이미지 초기화는 위치 0/0, 확대 1이다. 모바일 설정은 아래쪽 패널로 표시하며 문구/이미지 선택 목록을 제공한다.

## 관리자와 출력 분리

- HttpOnly + SameSite=Strict 서명 쿠키, 8시간 세션. HTTPS 요청에서는 Secure 쿠키. 무인증·변조 쿠키의 상세페이지 저장 요청은 401.
- 상세페이지 목록/의뢰서 편집/원본 API에도 인증 적용. 같은 출처의 JSON 요청만 변경 허용.
- `/preview?output=1`은 관리자 로그인 상태라도 편집기를 렌더하지 않는다. 비로그인 `/preview`도 공개 결과만 표시한다.
- 공개 결과에 설정·저장·편집 링크 및 관리자용 원문 속성을 포함하지 않는다. print CSS도 도구와 선택 표시, 편집기 여백을 숨긴다.
- 로그인 키 생성: `py -3 web/scripts/setup-detail-admin.py` (pipeline에서 실행). 기존 키는 덮어쓰지 않는다. 필요하면 서버 환경 변수 `DETAIL_ADMIN_KEY`로 별도 운영 키를 지정할 수 있다.
- 이 인증은 상세페이지 모듈용이다. 기존 숏폼 콘솔 전체를 인터넷 공개용 계정 시스템으로 전환한 작업은 아니다.

## 저장 구조

`상세페이지/<프로젝트 ID>/디자인.json`에 폰트, 색상, 문구 덮어쓰기, 개별 문구 스타일, 이미지 위치를 저장한다. 기존 `프로젝트.json`을 변경하지 않아 의뢰서 저장과 디자인 저장이 서로 지워지지 않는다. 디자인 revision과 파일 잠금으로 동시 저장 충돌은 409로 처리한다. 충돌 시 초안을 유지하고 JSON 다운로드를 제공한다. 화면 이동 시 미저장 변경을 안내한다.

이번 편집 렌더러는 현재 LUMEN 5컷 시안에 연결했다. 고딕/명조/고정폭은 로컬 폰트 스택이며 외부 폰트 업로드, 이미지 교체·회전, 섹션 순서 변경은 포함하지 않는다.
