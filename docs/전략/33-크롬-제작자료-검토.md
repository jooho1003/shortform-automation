# Chrome 제작자료 검토와 반영

2026-09-12 열린 Chrome 창·탭을 조사했다. 동일 URL은 하나로 합쳤으며, 조사 중 다른 작업에서 이동·재생성된 탭은 새 목록으로 다시 확인했다. 자료 페이지의 설명을 검토한 것이며 외부 서비스의 실제 생성 품질·요금·기능을 실험한 것은 아니다. 본문 프롬프트·폰트·영상·효과음 파일을 통째로 복제하지 않았다.

## 완료 기록

입력·저장·동시 수정 API 13개 검증 및 TypeScript 검사 통과. 본문이 확인된 자료만 기능 설계 근거로 삼았고, 접근 실패 자료는 위 표에 명시했다. 영상·이미지 신규 유료 생성이나 SNS 게시는 실행하지 않았다.

최종 `next build` 종료 코드 0. 기존 `api/media`와 `runner`의 동적 파일 추적 경고 5개는 남아 있다. 새 상세페이지 라우트 빌드 오류는 없다.

Chrome에서 빈 목록 → 임시 의뢰서 생성 → 카피·연출 프리셋 → 실시간 미리보기 → 저장 → 새로고침 후 내용 유지를 확인했다. 저장 중 입력 비활성화와 제작 지시문 복사 성공 안내도 확인했다. 모바일 검사에서 문서 폭과 스크롤 폭이 같았고 중복 ID가 없었다. 검증 후 화면 크기 설정을 원복하고 임시 의뢰서 파일을 정리했다.

A 리트리버 회차에서 연출 가이드와 4가지 고정 조건이 표시되는 것을 확인했다. 1번 컷에 적은 임시 입력이 2번 컷에 섞이지 않고 1번으로 돌아오면 복원된다. 검증용 입력은 비웠다.

Markdown·제작 지시문의 사용자 입력 보존과 한국어 검수 라벨은 코드 실행으로 확인했다. 브라우저 자동화의 다운로드 이벤트는 포착되지 않아 실제 내려받은 파일까지 확인한 것으로 기록하지 않는다. 다운로드 구현은 숨긴 링크를 문서에 붙여 실행하고 Blob URL을 지연 해제하도록 보완했다.
