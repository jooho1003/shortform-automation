# 카드뉴스 · 인스타툰 자동화

2026-09-13. 콘솔에 `/cardnews`, `/instatoon` 두 페이지를 추가했다. 이번에 된 것은 **프로젝트 저장·편집·실물 크기 미리보기·게시 전 점검**까지다. 원고/콘티 LLM 생성, 이미지 생성, PNG 렌더, 게시는 아래 단계로 붙인다.

## 1. 리서치에서 정한 규격

| 항목 | 값 | 근거 |
|---|---|---|
| 슬라이드 크기 | **1080×1350 (4:5)** | Graph API 허용 비율 4:5~1.91:1. 3:4(1080×1440)는 앱에선 되지만 API 통과가 [미확인]이라 쓰지 않는다. [Meta IG User Media](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media/) |
| 장수 | **자동 게시 10장 이하** (앱 수동은 20장) | Graph API `children` 최대 10, Buffer도 이미지 10장. [Content Publishing](https://developers.facebook.com/docs/instagram-platform/content-publishing/) · [Buffer Help](https://support.buffer.com/article/657-scheduling-instagram-posts-and-reels) |
| 파일 | **JPEG**, 장당 8MB 이하 | Graph API는 JPEG만 받는다 |
| 캡션 | 2,200자 · 해시태그 30개 · 장별 alt_text 1,000자 | 같은 문서 |
| 첫 장 비율 | 모든 장이 첫 장 비율로 잘린다 | 같은 문서 → 전 장 같은 크기로 렌더 |
| 폰트 | **Pretendard (SIL OFL 1.1)** | 상업 이미지 삽입 자유, 폰트 파일 판매만 금지. [GitHub](https://github.com/orioncactus/pretendard) |
| 광고 표기 | 표지 이미지 안 + 캡션 첫 줄 맨 앞 | 추천·보증 심사지침(2024-12-01 시행): '더보기' 안·댓글·프로필 표기는 인정 안 됨 |

카드뉴스 구성(업계 관행, 1차 출처 없음): 표지 1장(후킹 제목 ~22자 이내) → 본문(한 장 한 메시지, 제목 + 2~3줄) → 마지막 CTA(저장·팔로우). 7~10장이면 API 한도와도 맞는다.

인스타툰 관행: 장당 1컷(대형) 또는 2~4컷, 10장 안팎. AI 제작 후기에서 공통으로 나온 실패는 **캐릭터가 컷마다 흔들림**과 **이미지에 그려진 글자가 작거나 깨짐**이다.

## 2. 핵심 설계 결정

### 2-1. 글자는 이미지 모델에 그리게 하지 않는다
이미지 모델은 **글자 없는 배경·삽화·컷**만 만든다. 제목·본문·말풍선·페이지 번호·'광고' 표기는 전부 React 컴포넌트가 얹는다. OpenAI 문서도 글자 배치가 부정확하다고 밝히고 있고, 상세페이지 작업(`detailTypes.ts sectionPrompt`)도 이미 같은 원칙이다. 덕분에 오탈자 수정·광고 표기 추가가 **재생성 없이 재렌더만으로** 끝난다.

### 2-2. 미리보기 = 출력물 (컴포넌트 하나)
`pipeline/remotion/src/carousel/CardSlide.tsx` · `ToonSlide.tsx`를 웹 콘솔이 `@composition/*`으로 직접 import해 1080×1350 원본을 축소 표시한다. 같은 컴포넌트를 `Root.tsx`에 `<Still id="CardSlide|ToonSlide">`로 등록해 두었으니 PNG 출력도 이 코드로 나온다. HTML→Playwright 스크린샷이나 Satori를 새로 들이지 않는다(Satori는 CSS 제약·한글 fallback 문제, Playwright는 새 의존성).

### 2-3. SSOT는 파일
```
카드뉴스/<id>/프로젝트.json · 이미지/NN.png · 출력/NN.jpg · 로그/
인스타툰/<id>/프로젝트.json · 캐릭터/<key>.png · 컷/SS-P.png · 출력/NN.jpg · 로그/
```
이미지 경로는 루트 기준 상대 경로로 저장한다. 웹은 `/api/media?path=`로 읽는다.

### 2-4. 인스타툰 캐릭터 일관성 = A안 영상 방식 그대로
`images_a.py`에서 검증된 방식을 옮긴다.
- 캐릭터마다 **락 블록**(외형·헤어·의상·색) 한 번 확정 → 이후 바꾸지 않음.
- **캐릭터 시트 1장**(정면·3/4·측면 + 표정 4~6)을 먼저 만들고 사람이 승인.
- 컷 생성 때는 **그 컷에 나오는 캐릭터의 시트만** `-i`로 첨부. 이전 컷은 붙이지 않는다(드리프트 누적 방지).
- 컷 프롬프트는 화풍 + 장면(행동·구도)만. 외형을 되풀이하지 않는다.
- 말풍선 자리를 비우도록 "상단 1/3 여백, 글자·말풍선 금지"를 넣는다.

### 2-5. 게이트
`draft → scripted(원고/콘티 승인) → illustrated(이미지 승인) → rendered → published`. 앞 단계 승인 없이 뒤 단계 잡이 돌지 않는다. 게시는 `confirmed` 없이는 불가(기존 runner `dangerous` 규칙).

## 3. 단계별 파이프라인

### 카드뉴스
| 단계 | 실행 | 입력 → 출력 |
|---|---|---|
| C1 원고 | `runLlm` claude, JSON 스키마 | 주제·타깃·브랜드(외주 고객이면 설문) → `slides[]`(role/eyebrow/title/body) + 장별 `image_brief`(글자 없음) + caption + hashtags. 스키마에서 10장·표지 22자·본문 3줄 제한 |
| C2 검수 | claude 1콜 (선택) | 사실 주장·효능 표현 표시. 화장품이면 표시광고 위험 문구 플래그만(판정은 사람) |
| C3 이미지 | Python `shortform carousel images` → codex `workspace-write` | `image_brief` → `이미지/NN.png`. 1088×1360 생성 후 축소. **테마 단색 카드는 이미지 생략 가능** — 쿼터 절약 |
| C4 렌더 | `@remotion/renderer` 스크립트: bundle 1회 + `renderStill` N회 | `프로젝트.json` → `출력/NN.png` → JPEG 변환 |
| C5 게시 | Buffer 확장(아래 5절) | 승인 필요 |

### 인스타툰
| 단계 | 실행 | 입력 → 출력 |
|---|---|---|
| T1 기획 | claude, JSON 스키마 | 로그라인·장르 → 캐릭터 락 블록 + 화풍 + 콘티(장·레이아웃·패널 장면·말풍선 초안) |
| T2 캐릭터 시트 | codex, 캐릭터당 1장 | 락 블록 → `캐릭터/<key>.png`. **사람 승인 게이트** |
| T3 컷 | codex, 패널당 1장, 시트 첨부 | `컷/SS-P.png`. 레이아웃별 비율(1컷 ≈4:5, 2컷 ≈16:9, 4컷 ≈5:6)로 생성, `object-fit: cover`로 맞춤. 실패 시 1회 재시도 후 manual 폴백. 재생성 지시는 A안 `clips_fix` 형식 재사용 |
| T4 말풍선 | 에디터에서 x/y 조정. 이후 claude 비전 1콜로 얼굴 피한 위치 제안(선택) | |
| T5 렌더 · T6 게시 | 카드뉴스와 동일 | |

비용 감각: 인스타툰 10장 × 평균 2패널 = 컷 20장, codex 호출당 ~3분 → **한 편 약 1시간 + 시트**. codex 이미지 생성은 텍스트보다 구독 쿼터를 3~5배 빨리 쓴다(`20-A안-AI생성-영상.md`).

## 4. 렌더 세부

- **폰트:** Pretendard woff2를 `remotion/public/fonts/`에 넣고 `FontFace` + `delayRender`로 로드 완료 후 렌더. 기존 `render-static-feed` 스크립트에서 "글리프가 일부 빠진 still"이 나왔던 원인이 폰트 로드 대기 부재로 보인다 — 렌더 후 PNG를 자동 점검(빈 사각형 글리프는 사람이 확인)하는 단계를 둔다.
- **이미지 경로:** 렌더 시 `--public-dir`(renderer의 `publicDir`)을 프로젝트 폴더로 지정하고, 프로젝트 밖 경로 이미지는 lint에서 막는다. 저장소 전체를 public으로 잡으면 영상까지 번들에 복사된다.
- **JPEG:** PNG 렌더 후 ffmpeg(이미 의존성)로 `-q:v 2` 변환, 8MB 확인.

## 5. 게시

`buffer_api.py`는 현재 영상 전용(`assets: [{video}]`, `type: reel`)이다. 확장 방향:
- `assets`에 이미지 URL 목록(순서 유지), Instagram `type: post`.
- 이미지는 공개 HTTPS URL이어야 한다(영상과 같은 호스팅 문제).
- **Buffer GraphQL의 캐러셀 동작은 문서상 명시가 없다 [미확인]** → 초안(draft) 1건으로 실제 확인한 뒤 자동화한다. 안 되면 Graph API 직접(`is_carousel_item` → `CAROUSEL` 컨테이너 → `media_publish`)을 대안으로 둔다.
- 게시 전 lint `error`가 하나라도 있으면 전송 불가.

## 6. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 광고 표기 누락 | `sponsored`면 표지 '광고' 배지 자동 렌더 + 캡션 첫 줄 표기 없으면 lint error (구현됨) |
| Meta "AI info" 라벨 | C2PA 메타데이터는 지우지 않는다. 라벨이 붙는 걸 전제로 운영 |
| AI 캐릭터 저작권 | 프롬프트만으로 만든 산출물은 저작권 등록 불가. 기존 캐릭터·작가 화풍을 참조 이미지로 넣지 않는다 |
| API 10장 한도 | 11장 이상이면 lint warn, 게시 단계에서 차단 |
| 3:4 비율 | 실게시 1건으로 API 통과 확인 전까지 4:5 고정 |
| AI 기본법(2026-01-22 시행) | 외부 고객에게 서비스로 제공하면 표시 의무 대상일 수 있음 [미확인] — 외주 납품 시 확인 |
