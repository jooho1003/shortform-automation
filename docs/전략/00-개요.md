# 숏폼 전략 개요

작성일: 2026-09-08
상태: 확정

이 폴더는 **무엇을 어떻게 만들 것인가**를 담는다. 상시 문서다.
날짜 폴더(`숏폼/YYYY-MM-DD/`)는 그날 만든 산출물이고, `숏폼/pipeline/`은 그걸 만드는 코드다.

| 문서 | 내용 |
|---|---|
| `00-개요.md` | 이 문서. 두 안의 관계와 공통 원칙 |
| `10-B안-예능클립.md` | B안 구축 방법 (주력) |
| `11-템플릿-규격.md` | 숏폼 화면 템플릿 3종의 시각 규격 |
| `12-소스채널-후보.md` | 소스 채널 17개 실측과 추천 |
| `20-A안-AI생성-영상.md` | A안 구축 방법 |
| `90-구현-변경목록.md` | 현재 코드가 B안을 못 돌리는 지점과 할 일 |

## 1. 두 안의 관계

| | A안 | B안 |
|---|---|---|
| 만드는 것 | 없던 영상을 생성한다 | 있는 영상을 재편집한다 |
| 소재 | Codex 이미지 → fal.ai MiniMax H3 영상 | 인물 중심 유튜브 롱폼 클립 |
| 저작권 | 전부 자체 생산. 리스크 없음 | 원저작물 인용. 리스크 관리 대상 |
| 편당 비용 | 3~8달러 (영상 생성) | 0원 (다운로드·렌더만) |
| 편당 시간 | 길다 (시트 반복 + 컷별 생성) | 짧다 (롱폼 1개에서 10편) |
| 자동화 수준 | 게이트 기반 반자동 | 컨펌 2회 외 전부 자동 |
| 역할 | 자산이 쌓인다. 캐릭터가 곧 IP | 조회수가 빨리 쌓인다. 채널을 띄운다 |

**B안이 주력이다.** 채널을 먼저 띄우고, A안은 그 뒤 캐릭터 자산을 쌓는 별도 트랙으로 병행한다.
둘은 같은 파이프라인 코드와 같은 폴더 규칙, 같은 승인 게이트를 쓴다. 다른 건 소재를 어디서 얻느냐뿐이다.

## 2. 공통 원칙

### 조사 게이트

**조사 없이 기획하지 않는다.** `plan` 단계는 그 주의 조사 리포트가 없거나 7일 넘게
묵으면 멈춘다(종료 코드 1). 문서에 적어 두면 지켜지지 않아서 코드로 박았다.

```
python -m shortform research
```

설정은 `pipeline/config/research.yaml`, 결과는 `숏폼/YYYY-MM-DD/00-조사리포트.md`.

### 승인 게이트 3개

파이프라인은 승인 파일이 없으면 그 단계에서 멈추고 종료 코드 2를 낸다.

| 파일 | 막는 단계 | 사람이 보는 것 |
|---|---|---|
| `01-기획-승인.txt` | plan | 기획안 |
| `02-이미지-승인.txt` | clips | 컨택트시트 (실제로 쓰일 프레임) |
| `04-업로드-승인.txt` | upload | 완성본 mp4 |

승인 파일이 있어도 업로드는 사람이 한 번 더 말해야 실행한다. 되돌리기 어려운 외부 공개 동작이기 때문이다.

### 폴더 규칙

```
숏폼/
├─ 전략/                       이 폴더. 상시 문서
├─ pipeline/                   코드
└─ YYYY-MM-DD/
   └─ <트랙>-<번호>-<제목>/     편 단위 산출물
```

### 넘지 않는 선

- Content ID **회피** 목적의 화면 변형(반전·크롭·속도 조절)은 만들지 않는다. 인용은 하되 우회는 안 한다.
- 출처 표기는 허락을 대신하지 않는다. 표기했으니 괜찮다고 전제하지 않는다.
- 실존 계정을 흉내 내는 댓글 닉네임을 만들지 않는다.
