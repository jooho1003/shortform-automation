# A안 — AI 생성 영상

작성일: 2026-09-08
상태: 미착수 (B안 안정화 후 시작)

## 1. 무엇을 만드나

없던 영상을 만든다. 소재는 동물 일상물 또는 애니 캐릭터 요리 힐링물 중 하나로 고른다.
B안이 조회수를 빨리 쌓는 트랙이라면, A안은 **캐릭터라는 자산을 쌓는** 트랙이다.
캐릭터가 팔리면 그 자체가 IP가 되고, 저작권 리스크가 0이다.

B안이 자리를 잡기 전에는 시작하지 않는다. 편당 시간과 비용이 B안의 몇 배다.

## 2. 도구 분담

| 단계 | 도구 | 비용 |
|---|---|---|
| 기획·컷표 | Claude | 편당 수십 원 |
| 캐릭터 시트·키프레임 | Codex CLI (ChatGPT 구독) | 구독 쿼터 |
| 영상 생성 | fal.ai MiniMax H3 (reference-to-video) | 편당 3~8달러 |
| 렌더 | Remotion | 무료 |
| 수동 보완 | 힉스필드 / NewTake 웹 UI | 별도 |

Codex 이미지 생성은 ChatGPT 구독 쿼터를 텍스트보다 3~5배 빨리 쓴다.
한 편에 시트 3~5회 + 키프레임 8~12장으로 잡는다.

**편당 비용 상한 10달러.** 넘으면 파이프라인이 멈추고 알린다.

## 3. 게이트

기존 shortform 스킬의 게이트 3개를 이 파이프라인의 승인 구조에 맞춘다.

| shortform 스킬 | 이 파이프라인 |
|---|---|
| 게이트 1 컷 분해 승인 | `01-기획-승인.txt` |
| 게이트 2 시트 승인 + 게이트 3 키프레임 검사 | `02-이미지-승인.txt` |

시트와 키프레임을 한 번에 확인한다.

## 4. 기획안 형식

```
# 시놉시스
# 락 블록 4개 (CHARACTER / COSTUME / GLOBAL STYLE / NEGATIVE)
# 컷표 (컷 번호, TC, 렌즈, 액션, 필수/선택)
# 음향 설계 (환경음, 효과음, 무음 구간)
# 메타데이터
```

## 5. 이미지 단계

**핵심은 캐릭터 시트 한 장이다.** 이게 흔들리면 뒤가 전부 흔들린다.

1. **캐릭터 시트** — 레퍼런스 폴더의 부엉이 시트 구성을 따른다. 한 장 안에
   3면 턴어라운드, 표정 4~6개, 의상·소품 변형, 디테일 클로즈업을 담는다.
   Codex CLI에 락 블록을 넣어 생성하고, **마음에 들 때까지 이 한 장만 반복한다.**
2. **키프레임** — 컷마다 같은 시트를 참조 이미지로 첨부해 생성한다.
   앞 컷 결과를 참조하지 않는다. 오차가 누적되기 때문이다.
3. **검사** — `check_frames.py`로 비율 9:16, 짧은 변 720px 이상(시트는 1080px 이상),
   필수 컷 누락, 워터마크 의심을 자동 판정하고 컨택트시트를 만든다.
   짧은 변으로 재는 이유: 세로만 보면 비율은 맞고 너비만 모자란 이미지가 통과한다.
   시트 하한이 더 높은 이유: 시트 한 장이 모든 키프레임의 기준이라 칸당 해상도가 남아야 한다.
4. 좌우 일관성처럼 기계가 못 잡는 건 사람이 본다.

## 6. 소재 단계

fal.ai MiniMax H3 reference-to-video. 참조 이미지를 최대 9장까지 받는다.

- 컷마다 **키프레임 + 캐릭터 시트**를 함께 넣는다.
- 모션 프롬프트에는 컷표의 ACTION·CAMERA만 쓴다.
  **외모·의상·스타일은 다시 쓰지 않는다.** 참조 이미지가 이미 그 정보를 갖고 있고,
  텍스트로 중복해서 주면 서로 싸운다.
- 컷당 5초, 768p 기본. 필요한 컷만 2K.
- 실패한 컷은 `03-소재/실패.txt`에 적는다. 사용자가 힉스필드나 NewTake 웹 UI에서
  수동으로 만들어 같은 이름으로 넣으면 이어서 진행한다.

## 7. 렌더 차이

- 대사가 없으면 자막을 생략한다.
- 음향 설계(환경음, 효과음, 클라이맥스 뒤 0.5초 무음)를 Remotion 오디오 트랙으로 넣는다.
- 댓글 카드는 A안에서도 쓴다. 힐링물이므로 톤은 감탄·공감형으로 기획안에서 생성한다.

## 8. 검증 기준

시트 1장 + 키프레임 6장으로 30초 영상이 나오고, **얼굴이 컷 사이에서 유지되면** 성공이다.
