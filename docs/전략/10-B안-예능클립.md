# B안 — 예능 클립 (주간 화제성 추종)

작성일: 2026-09-08
개정: 2026-09-09 (하이타치 실측 반영)
상태: 확정

운영 원칙(포맷 규칙, TTS 예외, 오디오 후처리)은 `../설계/01-B트랙-운영전략.md`가
기준이다. 이 문서는 **무엇을 소스로 삼고 어떤 주기로 굴리는지**를 정한다.

## 1. 두 번 바뀐 기획

### 1차 전환 — TTS 중심에서 원음 중심으로

첫 기획은 TTS 내레이션이 정보를 나르고 화면이 배경을 까는 구조였다. 실제로 만들어 보니
레퍼런스와 질감이 달랐다. 레퍼런스는 **원본 대사와 표정이 콘텐츠 자체**다.

### 2차 전환 — 채널 고정에서 주간 화제성 추종으로

그 다음엔 "채널 하나를 골라 70% 집중"으로 잡았다. 하이타치(@hi_tachy) 실측이 이걸 뒤집었다.

| | 이전 | 지금 |
|---|---|---|
| 정보를 나르는 것 | TTS 내레이션 | 원본 대사와 표정 |
| 소스 | 채널 하나에 70% 집중 | 소스 풀을 매주 훑어 뜬 것을 고름 |
| 배치 단위 | 롱폼 1개 → 쇼츠 10개 | 주 1회 조사 → 3편 |
| 길이 | 15~30초 | 35~75초 |
| TTS | 필수 | 선택 |

## 2. 하이타치가 실제로 하는 것

2026-09-09 실측. 구독 6,670명, **숏폼 전용 채널**(`/videos` 0편).
조회 중앙 2.4만 / 최대 110만 / 최소 5,200.

**소스를 고정하지 않는다.** 설명란 `📸 🎥 I` 뒤가 출처인데 매 편 다르다.

| 편 | 출처 | 조회 |
|---|---|---:|
| 마! 이게 남자 아이가!! 🍚 | (이선민·정혁) | 110만 |
| 초고속 결혼하는 지예은♥️바타 | (지예은·바타) | 110만 |
| 달고 기름진게 최고야🍬 | 유퀴즈 | 12.6만 |
| 재석 행님 사랑 독차지 하는 방법💗 | 놀면뭐하니 | 9.7만 |
| 왜 이런 일은 허경환에게만...🤮 | 살롱드립 | 5,283 |

방송 예능(놀면뭐하니·유퀴즈·나혼자산다)과 유튜브 롱폼(짐종국·살롱드립·가짜김효연)을 섞는다.
**히트는 인물이 아니라 그 주 화제성에서 나온다.** 최근 업로드만 보면 유재석 계열이 많아
"인물 축"으로 보이지만, 조회수 상위는 전혀 다른 소재다.

### 제목과 설명 패턴

```
제목:  짧은 후킹 문구 + 이모지 + #해시태그 3개
       예) 재석 행님 사랑 독차지 하는 방법💗 #놀뭐 #유재석 #허경환

설명:  👩‍🎤꿀잼 하이라이트는 하이타치🎬
       @hi_tachy #해시태그 나열

       📸 🎥 I 놀면뭐하니
```

출처를 `📸 🎥 I` 뒤에 간결하게 적는다. 채널 슬로건을 매 편 반복해 정체성을 박는다.

Content ID 리스크를 어떻게 감당하는지 우리는 모른다. 유튜브 롱폼으로 먼저 굴려 보고
성과가 나면 그때 판단한다.

## 4. 주간 사이클

```
월요일  조사        python -m shortform research
          ↓        소스 10개 롱폼 조회수 상위 + 벤치마크 숏폼 성과
        조사리포트   숏폼/YYYY-MM-DD/00-조사리포트.md
          ↓
        후보 3개 선정 + 제목 훅 작성        ← 기획 컨펌 (3편 한 번에)
          ↓
        편 폴더 3개
          ↓
        클립 컨펌 → 렌더 → 업로드 승인      ← 편별로 진행
```

**주 3편.** 조사를 편마다 하지 않고 주 1회로 묶는다.

### 조사 게이트

`plan` 단계는 조사 리포트가 없거나 7일 넘게 묵으면 **멈춘다**(종료 코드 1).
문서에 "조사 먼저"라고 적어 두면 지켜지지 않아서 코드로 박았다.
유효 기간은 `research.yaml`의 `freshness_days`.

### 후보 구간을 고르는 신호

- 웃음소리, 박수, 비명 (오디오 에너지 급상승)
- 3초 이상의 정적 뒤 반응
- 말이 겹치거나 끊기는 지점 (당황·반박)
- 자막에 물음표·감탄사가 몰리는 구간
- 숫자·순위·금액이 나오는 구간

1차는 기계가 뽑고 최종 3개는 사람이 고른다.

### 편당 규격

- 길이 35~75초
- 첫 1~2초에 결과나 감정이 드러나는 제목 훅
- 하드컷만. 전환 효과 없음
- 반응·표정·반전이 끝나는 지점에서 종료

## 5. 무엇을 고를 것인가

고정 비율(주력 70% 같은)을 두지 않는다. 축을 고정하지 않기로 했으므로 의미가 없다.
대신 **그 주의 신호**를 따른다.

1. 소스 풀에서 최근 조회수가 오른 롱폼
2. 벤치마크(하이타치·김갈대)가 최근 잘 뽑은 장면의 **유형** — 그대로 베끼지 않고 구조만
3. 우리 채널 지난 편 중 잘 된 것의 유형

10편·30편·50편 시점에 어떤 소스·어떤 감정이 먹혔는지 다시 본다.
성과 편차가 크다는 걸 기억할 것 — 하이타치는 5,200부터 110만까지다.
**다작으로 히트를 찾는 게임이지 한 편을 다듬는 게임이 아니다.**

## 6. 권리 처리

원음을 그대로 쓰므로 리스크는 첫 기획보다 크다. 세 단계로 관리한다.

**1단계 — 사전 동의를 먼저 시도한다.**
쪼꼬미필름은 설명란에 "영상 소유자의 동의를 받은 영상만 사용하고 있습니다"라고 명시한다.
소스 채널에 클립 사용 문의를 보내는 게 가장 확실하고 비용도 0이다. 개인 유튜버는 방송사보다
응답 가능성이 높다. 소스 풀이 유튜브 롱폼 위주인 이유이기도 하다.

**2단계 — 동의를 못 받으면 인용 요건을 갖춘다.**
저작권법 제28조는 비평·보도 목적의 정당한 인용을 허용한다. 관건은 해설이 주(主),
클립이 종(從)이어야 한다는 것이다. 제목의 관점, 장면 선택, 맥락 자막에서 채널 고유의
가치를 만든다. 단순 하이라이트 이어붙이기는 이 논리가 서지 않는다.

**3단계 — 결과를 전제하지 않는다.**
Content ID 처리는 권리자 설정에 따라 수익 귀속·추적·차단으로 갈린다. 별도 삭제 요청도
가능하다. "클레임 붙어도 영상은 살아 있다"를 전제로 운영하지 않는다.

설명란에는 인용한 영상의 제목·채널·URL과 인용 고지를 자동으로 넣는다.
