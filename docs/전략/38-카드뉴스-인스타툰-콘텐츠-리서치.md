# 카드뉴스 · 인스타툰 콘텐츠 리서치와 파일럿 기획

작성일: 2026-09-14  
범위: 형식 선택, 소재 방향, 파일럿 1회차씩. 게시 실행은 제외.

## 결론

- **카드뉴스는 저장 가치가 분명한 실용 정보**에 쓴다. 2025년 데이터를 담은 Metricool 2026 연구에서는 캐러셀이 단일 이미지보다 도달·노출이 높고 상호작용이 3배 이상이었다. Socialinsider의 1,500만 게시물 분석에서도 캐러셀이 세 형식 중 저장 중앙값과 저장률이 가장 높았다.
- **인스타툰은 공감 가능한 작은 실패와 반전**에 쓴다. 국내 만화산업백서는 인스타툰을 일상툰·생활툰·브랜드툰·육아툰·반려동물툰·연애툰·가족툰·공감툰 등으로 구분하며, 2024년 8월 `#인스타툰` 게시물을 약 231만 건으로 집계했다.
- 두 형식은 경쟁시키지 않는다. 같은 타깃에게 카드뉴스는 “저장할 도구”, 인스타툰은 “나도 저랬다며 댓글 달 이야기”를 맡긴다.

## 파일럿 A — 카드뉴스 1회차

- 제목: **혼자 만들수록 먼저 정할 5가지**
- 타깃: 결정 피로와 재작업이 많은 1인 사업자·초보 크리에이터
- 약속: 자동화 도구를 고르기 전에 정할 최소 기준을 30초 안에 점검
- 구조: 표지 → 목표 행동 → 한 사람 → 출처 → 반복 구조 → 품질 기준 → 작은 자동화 → 저장 CTA
- 시각: 크림 바탕, 네이비 활자, 코랄 포인트. 이미지를 쓰지 않아 정보 밀도와 재편집성을 우선한다.
- KPI: 저장률, 마지막 장 도달, 프로필 방문
- 프로젝트: `카드뉴스/20260914-solo-creator-check/프로젝트.json`

## 파일럿 B — 인스타툰 1회차

- 제목: **30분이면 된다며 시작한 첫 자동화**
- 타깃: 툴부터 크게 연결하다 지친 1인 제작자
- 감정선: 자신감 → 과욕 → 오류 → 탈진 → 발견 → 단순화 → 긴장 → 작은 성공
- 구조: 2장 × 4컷 = 8컷. 캐러셀 한 장마다 작은 절벽을 둔다.
- 캐릭터: 자체 캐릭터 ‘모모’. 외형 락 블록과 참조 시트를 프로젝트에 저장한다.
- 제작 원칙: 원화에는 글자를 넣지 않고 React 말풍선으로 합성한다. 오탈자 수정 시 원화를 다시 만들 필요가 없다.
- KPI: 댓글률, 공유율, 2장 도달
- 프로젝트: `인스타툰/20260914-first-automation/프로젝트.json`

## 게시 전 확인

1. 실제 휴대폰 크기에서 본문과 말풍선이 한 번에 읽히는지 본다.
2. 카드뉴스 1장은 한 메시지만 남기고, 인스타툰 말풍선은 장면을 설명하지 않고 감정만 보탠다.
3. 캡션 첫 두 줄만으로도 주제와 보상이 보이게 한다.
4. 광고 전환 시 `sponsored: true`, 이미지 표지와 캡션 맨 앞의 광고 표기, Instagram 유료 파트너십 라벨을 함께 확인한다.
