# 숏폼 템플릿 규격

작성일: 2026-09-08
상태: 초안 (픽셀값은 Remotion Studio에서 실물 보고 조정할 시작값)

프레임은 셋 다 1080x1920 / 30fps다.

**길이 (2026-09-11 확정)**: **15~75초, 강제 대신 경고.** 근거가 양쪽에 있었다 —
하이타치(@hi_tachy) 실측은 40·41·53·56·75초로 길고, 사용자가 보내준 레퍼런스 3편은
17·27·18초로 짧다. 한쪽을 고르는 대신 둘 다 받고, 범위를 벗어나면 멈추는 대신 경고만 찍는다.
`pipeline/config/templates.yaml`이 이 값이다.

## 템플릿 선택

| 상황 | 템플릿 | 길이 |
|---|---|---|
| 가볍고 웃긴 예능, 호감·공감 | `화이트 피드 카드` | 15~75초 |
| 갈등, 반전, 긴장, 충격 | `블랙 피드 카드` | 15~75초 |
| 해설·정보 전달이 중심인 예외 | `브리핑 포커스` | 35~60초 지침 |

기획안에서 `# 템플릿` 절에 한글 표시명을 정확히 적는다. 생략하면 `브리핑 포커스`다.

---

## 1. 화이트 / 블랙 피드 카드

주력 포맷이다. 유튜브 피드에 올라온 게시물처럼 보이게 만드는 구성이다.
위에서부터 **제목 → 클립 → 댓글 → 채널 크레딧** 순으로 쌓고, 아래는 비운다.

```
┌──────────────────────────┐  y=0
│                          │   배경 (흰색 또는 검정)
│      덜 익은 토마토        │  y=150   제목 1줄 (기본색)
│      이게 디테일           │  y=230   제목 2줄 (강조색)
│                          │  y=360
│  ┌────────────────────┐  │  y=430
│  │   원본 클립 16:9     │  │          1080 x 608, 크롭 없음
│  │  「여기 안 보였다」   │  │          강조 자막은 클립 위에 얹음
│  └────────────────────┘  │  y=1038
│  ┌────────────────────┐  │  y=1058
│  │ ● 닉네임             │  │          댓글 밴드
│  │   이 조합 찬성이요…   │  │
│  │   👍 494    답글      │  │
│  └────────────────────┘  │  y=1230
│      🅐 침착맨 플러스      │  y=1260   채널 크레딧
│                          │  y=1340
│      (비움)               │           쇼츠 UI가 덮는 영역
└──────────────────────────┘  y=1920
```

### 배경

| 템플릿 | 배경 | 제목 기본색 | 댓글 밴드 |
|---|---|---|---|
| 화이트 피드 카드 | `#FFFFFF` | `#111111` | 흰 카드 + 회색 테두리 |
| 블랙 피드 카드 | `#0A0A0A` | `#FFFFFF` | 흰 카드 |

### 제목

- 2줄 고정. 1줄은 상황, 2줄은 관점이나 반전.
- 굵은 고딕. 시작값 62px, 행간 1.25, 가운데 정렬, 최대 폭 900px.
- **2줄만 강조색을 쓴다.** 감정에 따라 고른다.

| 감정 | 강조색 | 예 |
|---|---|---|
| 정보·감탄 | `#2F6BFF` 파랑 | 이게 디테일 |
| 발견·전문성 | `#22C3E6` 청록 | 입시생으로 위장했다 |
| 웃김·귀여움 | `#F5C518` 노랑 | 못 피하는 하트 |
| 충격·갈등 | `#E5322D` 빨강 | 뭐하는 거야 |

- 한국어는 `word-break: keep-all`. 어절 중간에서 끊지 않는다.

### 클립

- **크롭하지 않는다.** 16:9 원본을 1080 폭에 그대로 맞춘다 (1080x608).
  피드 카드는 "게시물을 보는" 구성이라 블러 레터박스도 쓰지 않는다.
- 세로 원본이면 폭 1080에 맞추고 높이는 최대 1000px까지 허용, 아래 블록을 그만큼 내린다.
- 강조 자막은 클립 위에 얹는다. 대사를 그대로 옮기지 않고 **핵심 단어와 감정만** 남긴다.
  아직 강조 자막 표를 파싱하지 않으므로 **원음 편에는 자막을 얹지 않는다.** 대본의 `문장`은
  구간을 찾고 검토하기 위한 대사 받아쓰기라 화면에 띄우면 안 되고, 원본에 방송 자막이
  이미 박혀 있어 겹치기도 한다. TTS가 있는 편에서만 그 문장을 자막으로 띄운다.
- 원본 오디오를 그대로 쓴다. BGM은 대사가 나올 때 자동으로 낮춘다.

### 댓글 밴드

- 첫 댓글을 **0초부터 고정 표시**한다. 이후 댓글은 지정 시각에 교체한다.
  (`브리핑 포커스`처럼 아래에서 올라오지 않는다.)
- **프로필과 닉네임은 블러로 가린다.** 지어낸 값이라 실존 계정으로 읽히면 안 된다.
  일부러 가린 티가 나게 — 색상 원의 테두리는 살리고 안쪽만 뭉갠다. 댓글 내용은 그대로 보인다.
- 좋아요 수와 `답글`은 표시만 하는 장식이다.

### 채널 크레딧

- 소스 채널명을 원형 로고와 함께 하단에 표시한다. 인용 표시의 일부다.
- 설명란의 출처 표기와 별개로 화면에도 남긴다.

## 2. 브리핑 포커스

해설이 중심인 예외 포맷이다. `2026-09-08/B-01-시청률TOP3공통점`이 이 템플릿으로 만들어졌다.

- 클립이 화면을 채운다. 가로 소재는 높이 940px 띠로 확대해 y=200에 얹고 나머지를 같은 화면의 흐린 확대본으로 채운다.
- 자막은 하단 중앙, 어절 단위 하이라이트(현재 읽는 어절만 노란색).
- 댓글 카드는 지정 시각에 화면 아래에서 스프링으로 올라와 3.4초간 머문다.
- TTS 내레이션이 정보를 나른다. 이 템플릿에서만 TTS가 기본이다.

**한계**: 어절 타이밍은 추정값이다. edge-tts가 `WordBoundary`를 주지 않아 문장 구간
(`SentenceBoundary`, 정확)만 받고 그 안에서 글자 수 비례로 나눈다. 몇십 ms 어긋난다.
이 템플릿을 자주 쓰게 되면 강제 정렬기나 유료 TTS를 다시 검토한다.

## 3. 공통

- 하드컷만. 전환 효과 없음.
- 하단 580px은 비운다. 유튜브 쇼츠 UI(좋아요·댓글·공유·채널명·캡션)가 덮는 영역이다.
- 오디오는 최종 믹스를 통합 음량 약 `-16 LUFS`, 최대 피크 `-1 dBTP`로 정규화한다.
- 노이즈 제거는 실제로 들릴 때만. 과하게 걸어 목소리가 금속성이 되면 원음을 유지한다.
