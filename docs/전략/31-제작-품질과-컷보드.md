# 제작 품질과 컷별 검토

2026-09-12. 기존 A안 생성 파이프라인과 회차 상세 화면에 적용하는 개선이다. 기존 완성본을 자동으로 다시 만들거나 게시하지 않는다.

## 화면에서 쓰는 순서

1. 회차 상단의 다음 작업 안내로 필요한 탭을 연다.
2. A안의 시트·키프레임 화면에서 캐릭터 기준 이미지와 고정 스타일을 확인한다.
3. 컷마다 동작, 카메라, 길이와 실제 이미지·영상 파일을 비교한다. 파일이 있다는 표시는 품질 승인과 별개다.
4. 바꿀 이미지 컷을 선택하고 구체적인 수정 내용을 적어 요청을 저장한다. 저장만으로 생성되지는 않는다.
5. 실행·로그에서 시트·키프레임 단계를 실행한다. 이미 완료된 단계라면 다시 실행 옵션을 켠다. 생성기는 설정된 이미지 제공자를 사용한다.
6. 결과를 검토하고 이미지 승인을 진행한다. 기존 컷 영상과 완성본은 자동 교체하지 않으므로 새 이미지 반영 여부를 따로 확인한다.

기존 수정 요청이 남아 있으면 새 요청으로 덮어쓰지 않는다. 필요한 수정은 한 번에 묶어 저장한다. 기존 이미지는 재생성 백업 폴더에 보관한다.

## A안 품질 기준

- 캐릭터 시트는 같은 의상과 소품을 여러 각도에서 보여준다. 의상 변형안은 섞지 않는다.
- 키프레임은 동작을 시작할 한 장면이다. 여러 순간을 한 그림에 합치지 않는다.
- 영상 생성에는 캐릭터·의상·전체 스타일·금지 요소를 함께 전달한다.
- 리트리버는 얼굴 비율, 앞발 형태, 꼬리 수, 앞치마와 주방의 배치가 유지되는지 확인한다.
- 한 컷에서 한 가지 주동작을 사용하고 불안정한 동작은 컷을 나눈다. 장면의 구체적인 수정은 컷표에도 반영하면 다음 제작에 유지된다.

프롬프트 개선은 생성 조건을 명확히 하는 조치다. 실제 결과의 얼굴·동작·음향 품질은 생성 후 검토해야 한다.
