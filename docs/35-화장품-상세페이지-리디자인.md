# 화장품 상세페이지 리디자인 — 2026-09-12

이전 ONGI 머그 시안은 사진 하나를 반복했고 화장품 참고자료를 충분히 구현하지 못했다. 별도 가상 브랜드 LUMEN DEW SERUM으로 5컷 시안을 제작했다.

## 결과

- 독립 HTML: `상세페이지/db6b2f93-2d77-436c-b560-8d9ab2208102/화장품-리디자인.html`

- 전체 생성 프롬프트: 동일 결과 폴더의 `이미지-프롬프트.json`. 패키지 생성에는 먼저 확인한 hero 이미지를 참조했다.

## 반영 내용

| 역할 | 새 이미지 | 페이지 정보 구성 |
|---|---|---|
| 제품 대표컷 | 세이지 유리 보틀, 물보라, 아크릴 블록 | 큰 한글 제목, 브랜드, 제품 이름 |
| 제형 확대 | 피펫, 투명 제형, 굴절 | 사진 내부 세 개의 한글 콜아웃 |
| CGI | 수분 구체와 투명한 세 겹 레이어 | 한글 제목과 설명, 범례, 개념 연출 각주 |
| 사용 장면 | 손등 위 피펫 한 방울 | DROP / SPREAD / ROUTINE 설명 |
| 패키지 | 동일 보틀과 아이보리 상자 | 마무리 브랜드 카피 |

기존 화장품 CGI 자료에서 읽었던 수분막·레이어 개념을 시각 구성으로 적용했다. 참고자료의 모든 항목을 넣었다는 뜻은 아니다. 실제 제품의 전성분·규격·효능 근거가 입력되지 않은 가상 시안이다. 자료의 CGI 아이디어를 제품 효능 사실로 변환하지 않았다. 이번 웹 도구 재열람은 실패했으며 기존 열람 범위는 문서 33에 기록되어 있다.

문구는 이미지 위 HTML/CSS 오버레이로 배치한다. PNG 자체에 모든 한글 문구가 구워져 있는 형태는 아니다. 최종 HTML에는 이미지와 문구가 함께 포함된다. 향후 이미지 납품은 최종 사이즈 확정 후 별도 래스터 출력이 필요하다.

## 검증

- `npm run typecheck --workspace=shortform-web`: 통과 (UI 작업).
- `npm run build --workspace=shortform-web`: 통과. 기존 media/runner 동적 파일 추적 경고 5개 유지.
- `py -3 web/tests/export-beauty-sample.py`: 통과. 이미지 5개 각각 한 번, SHA-256 다섯 개 모두 다름, 프로젝트 제목 다섯 개 포함, script 없음. 최종 HTML 13,861,075 bytes.
- Chrome 실제 페이지: 이미지 5개 로딩 성공, 데스크톱 clientWidth=scrollWidth=1905. 제품/3D/루틴 구간 직접 화면 확인. 제형 문구는 사진 컨테이너 내부로 이동했다.
- 모바일 CSS는 구현했으나 이번 viewport override가 실제 브라우저 폭에 반영되지 않아 모바일 실화면 검수는 미완료다. 통과로 기록하지 않는다.

## 제작 기준

외주 시안에서 사진 한 장의 확대·재사용을 독립 컷으로 세지 않는다. 먼저 각 섹션의 목적과 독립 이미지 목록을 확정하고 제품 정체성을 참조 이미지로 유지한다. 한글은 편집 가능한 텍스트로 조판하며 제형·원리 CGI에는 시각 근거의 성격을 명시한다. 실제품 자료 수령 후 사실·사용법·구매 조건을 교체하고 납품 검수한다.

현재 고급 화장품 레이아웃은 이 샘플 ID에 적용된 시안이다. 모든 의뢰서에서 5컷 자동 생성되는 기능이나 서비스 API 연동이 완성된 것은 아니다.
