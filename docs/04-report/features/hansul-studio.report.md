# 한술툰 작업실 완료 보고

작성일: 2026-10-01

## 제공한 흐름

`/instatoon` → 한술툰 → 다음 화 생성 → 주제(자동/직접) → 콘티(자동/직접) → 검토·수정 → 수정 반영 재생성 → 콘티 승인 → 기존 컷 편집기.

- 작품 규칙과 앞 회차를 생성 문맥에 포함한다.
- 제목·핵심 갈등·3화 흐름·장면·대사·표정·캡션을 직접 편집한다.
- 생성 전에 현재 편집본을 저장한다. 버전 기록과 읽기 전용 미리보기·복원을 제공한다.
- 오래된 탭 저장, 중복 생성, 빈 콘티 승인과 출력 잘림을 검증한다.
- 원본 1화 도시락 콘티와 실제 생성한 2화 초안을 준비했다. 최종 승인 여부는 모두 검토 전으로 남겼다.

## 저장 위치

- 문서: `인스타툰/시리즈/hansul.json`
- 생성 로그: `인스타툰/시리즈/로그/`
- 승인한 컷 프로젝트: 기존 `인스타툰/<id>/프로젝트.json`
- 원래 `한술툰/기획/` 문서와 캐릭터 이미지 원본은 보존한다.
