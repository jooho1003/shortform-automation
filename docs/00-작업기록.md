## 2026-09-08 — 설계 승인부터 첫 렌더까지

### 시작점

- 설계 문서(`docs/설계/00-파이프라인-설계.md`) 승인. B 트랙(스톡+TTS 완전자동) 주력, A 트랙(AI 생성) 병행.
- 환경: Python 3.11, Node 22, ffmpeg 8.1, uv. **API 키 전무.**

### 결정 1 — 주제를 정보·팁형에서 엔터로

정보·팁형 후보 4개(건강 습관·생활비·음식·시간관리)를 제시했으나 사용자가 전부 물리고
**"예능·엔터·영화·드라마처럼 사람들이 관심 있어할 것"** 으로 방향 전환. 발굴은 인급동·조회수
상위·재사용 허용 세 갈래로.

### 결정 2 — 화면은 안전 소재로 (나중에 뒤집힘)

"재사용 허용" 필터로 나온 영상을 화면에 그대로 쓰는 것의 리스크(CC 표시가 잘못된 재업로드,
유튜브 재사용 콘텐츠 정책)를 설명. 사용자가 **"주제만 엔터, 화면은 안전(스톡)"** 선택.

### 구현 — 파이프라인 골격

`pipeline/` 에 CLI(`new/run/status/discover`), 승인 게이트 3개, `상태.json` 재개, Remotion 컴포지션.
합성 클립으로 assets→render 전 구간을 돌려 mp4까지 확인.

**삽질 1 — edge-tts는 WordBoundary를 안 준다.** 7.2.8 기준 한국어·영어 모두 `SentenceBoundary`만
온다. 설계의 whisper 재전사도 답이 아니다 — whisper는 강제 정렬기가 아니라 전사기라 대본과
퍼지 매칭이 필요하다. 문장 구간(정확)만 받고 그 안에서 어절을 글자 수 비례로 배분하기로.

**삽질 2 — 한글 경로에서 `pip install -e .`가 파이썬 기동을 깬다.** `.pth` 파일을 cp949로
읽다 `UnicodeDecodeError`. editable 설치를 걷어내고 `pipeline/`에서 직접 실행.

**삽질 3 — 한국어 자막이 어절 중간에서 줄바꿈.** CSS 기본 `word-break`가 CJK를 아무 데서나
끊는다. `word-break: keep-all` + 어절 `inline-block`.

### 1편 기획 — "2026 시청률 TOP3 드라마의 공통점"

YouTube API 키가 없어 발굴 단계를 건너뛰고 WebSearch로 트렌드 확보. 시청률 1위 '21세기
대군부인'(13.8%), 2위 '판사 이한영'(13.6%), 3위 '언더커버 미쓰홍'(13.1%). 기획안에 **확인 필요**
3건을 명시 — 수치가 기사 1건 기준, 미쓰홍 설정은 제목에서 추측.

### 결정 3 — Pexels 키 발급, 기획 승인

**삽질 4 — Pexels 403은 키 문제가 아니었다.** Cloudflare 에러 1010, `Python-urllib` User-Agent
차단. 브라우저 UA를 붙이니 통과. 검색·썸네일·영상 다운로드 세 경로 전부 적용.

**삽질 5 — 기획안 표에 에디터가 빈 행을 넣어 파서가 `int("")`로 죽음.** 빈 행 방어.

**삽질 6 — 컨택트시트 라벨이 셀 폭을 넘어 옆 칸 침범.** 글자 수가 아니라 실제 렌더 폭으로 자름.

스톡 검색어를 세 번 조정(2·4·8번). "royal palace interior"는 유럽 성당을, 재검색은 **중국 한푸**를
물어왔다. 회전으로는 해결 안 되고 장소로 좁혀야 잡혔다.

### 결정 4 — 스톡을 버리고 실제 방송 클립으로 (결정 2를 뒤집음)

사용자가 스톡 결과물을 보고 **"이지컷은 실제 장면을 인용하는데?"** 지적. 맞는 지적이었다 —
법봉·도미노·경복궁은 드라마 얘기를 하는 화면이 아니라 배경이었다.

Content ID 클레임 가능성과 수익화 불리함을 다시 설명. 선택지 4개(하이브리드·전부 실제·예고편만·
스톡 유지) 중 사용자가 **"전부 실제 장면"** 선택.

넘지 않기로 한 선: Content ID **회피** 목적의 화면 변형(반전·크롭·속도 조절)은 만들지 않는다.

### 구현 — 방송 클립 조달

- `clip` 소재 태그 추가. **yt-dlp로 유튜브 검색 → API 키 불필요.** 채널명에 방송사가 들어간
  후보를 앞으로 정렬해 10줄 전부 공식 채널(MBCdrama·tvN DRAMA·Disney+·드파밍·디글)이 1순위.
- **컨택트시트에 썸네일 대신 실제 발췌 지점 프레임.** 썸네일은 문구가 박힌 홍보 이미지라
  화면에 깔릴 장면과 다르다. 스트림 URL에 seek해 한 장만 뽑음. (이 방식은 이틀 뒤 `segments`에서
  실패한다 — 짧은 예고편에선 되고 36분 롱폼에선 안 된다.)
- 발췌 지점 3건 손봄(3·6·7번). 7번은 고른 영상 자체가 "3년 후" 에필로그라 왕실 장면이 없어
  후보를 바꿈.
- **대본 3문장 수정.** 검색으로 확인된 사실이 기존 문장과 어긋났다 — 언더커버 미쓰홍은
  회귀·빙의물이 아니라 "금융감독관이 신입사원으로 위장 잠입". 확인 필요 3번이 이렇게 해결됨.

## 2026-09-10 — 구간 추출

### 구현 — `segments`

롱폼 1편에서 숏폼 구간 후보 20개. 신호: ffmpeg ebur128 음량 시계열 + yt-dlp 자동 자막.
추가 의존성 0.

**핵심 발견 — 자막의 `[웃음]` 마커.** 유튜브 ASR이 직접 붙이는 표시. 36분 영상에 92개.
음량 추정보다 정확해서 1순위 봉우리로 쓰고 음량은 보충용. 원래 설계엔 없던 신호.

**삽질 12 — 음량 임계값.** `median+1.1*sd`가 21,612개 중 **2개**만 통과. 압축 오디오는 위쪽
여유가 7dB뿐인데 무음(-69dB)이 표준편차를 부풀려 임계값이 99백분위보다 높아짐. 백분위로.

**삽질 13 — 봉우리를 시간순으로 집으면 약한 게 자리를 차지.** 강한 것부터.

**삽질 14 — 유튜브 자동 자막은 2줄 롤링.** 각 큐가 "이전 줄 + 새 줄"이라 이어붙이면 말밀도가
초당 **40자**(실제 8~10자). 마지막 비어 있지 않은 줄만 새 내용. `&gt;` 엔티티 디코딩도.

**삽질 15 — 원격 스트림 seek.** 36분 영상 중반 한 지점에 120초 초과, 20개 중 **1개**(0초)만
성공. 360p를 통째로 받아 로컬에서 뽑기. 캐시되니 재실행 즉시.

**삽질 16 — 프레임 캐시가 순번 기준.** 후보가 바뀌면 엉뚱한 프레임 재사용. 시각 기준으로.

인트로 60초·엔딩 30초 제외(0:26 타이틀 카드가 후보로 잡혔었다).

검증: 할명수 "극T 혜리 VS 극F 황인엽" 36분 → 상위 구간 3:16(51.5점)
"제 팬입니까? / 그런 거 같아요 [웃음] / 전화번호 교환할 생각 / 바로 가겠습니다". 실제로 쓸 만함.

**남은 약점:** 롱샷이 섞임(기계가 클로즈업 구분 못 함), 점수 변별력 약함(31.8~51.5). 가중치는
근거 있는 값이 아니라 시작값 — 몇 편 만들어 성과와 연결해 봐야 조정 가능.

- `PlanA`·`PlanCut` 타입을 추가하고 `EpisodeDetail.plan`을 `Plan | PlanA | null`로

  폴더명과 기획안 내용이 어긋나도 화면이 안 터진다
- A안은 README가 원래 약속하던 대로 시놉시스·락 블록·컷표·음향 설계를 보여준다.
  구현이 없었을 뿐 화면 정의는 이미 있었다

`tsc --noEmit` 통과, `/ep/A/...`와 `/ep/B/...` 둘 다 200, B안 대본 표 회귀 없음.

## 원음 중심 구현 — 템플릿이 내레이션 방식을 정한다

첫 피드 카드를 만들려다 보니 **오디오를 세 군데에서 버리고 있었다.** 원음이 콘텐츠인
포맷에서 하나도 남김없이 막혀 있던 셈이다.

1. `assets.py _to_9x16()`가 `-an`으로 클립 오디오를 버린다
2. `assets.py run()`이 문장별 TTS를 강제하고 그 길이로 타임라인을 만든다
3. `FeedCard.tsx`·`Short.tsx`가 `<OffthreadVideo muted>`로 못을 박아 뒀다

`config/templates.yaml`에 `narration`을 넣어 갈랐다. `tts`(브리핑 포커스)는 기존 그대로,
`original`(두 피드 카드)은 TTS를 만들지 않고 **클립 구간 길이가 타임라인**이 된다. 길이는
`클립목록.json`의 `seconds`가 정하고, 없으면 줄 번호를 알려주며 멈춘다. 항목을 적지 않은
템플릿은 `tts`로 보므로 기존 카탈로그가 그대로 돈다.

렌더 쪽은 **타임라인에 스위치를 따로 두지 않았다.** `muted={Boolean(narration)}` — 내레이션이
없으면 원음이 들린다. 스위치가 둘이면 언젠가 어긋난다.

`-filter_complex`를 쓰는 가로 소재는 매핑이 명시로 바뀌므로 `-map 0:a?`를 함께 줘야 했다.
`?`가 없으면 오디오 없는 소재에서 죽는다.

**남은 것**: BGM 덕킹. 지금은 BGM(volume 0.1)이 원음과 그냥 겹친다.

# 받은 파일이 이미 발췌 지점부터 시작하므로 여기서 다시 건너뛰지 않는다
_to_9x16(src, out, needed, 0.0, display_size)

주석은 구간 받기 기준으로 맞지만 **폴백에서는 거짓이다.** 통째로 받은 76분 파일을 0초부터

실제로 첫 결과물이 그렇게 나왔고, 프레임을 뽑아 보고서야 알았다.

이제 잘라낼 지점을 `cut_from`으로 명시해서 넘긴다. 폴백이라는 개념 자체가 없어졌다.

## 렌더 경로 선택 — Remotion / CapCut

CapCut을 병행하기로 해서 회차마다 경로를 고를 수 있게 했다.

- `<회차>/렌더설정.json` = `{"route": "remotion" | "capcut"}`. 없으면 remotion
- 웹 콘솔 `실행` 탭에 라디오 버튼 (`RenderRoutePicker.tsx`)
- `render.py`가 같은 파일을 읽는다. capcut이면 자동 렌더 대신 안내를 내고 멈춘다

**CapCut은 내보내기를 자동화할 방법이 없다.** 커뮤니티 MCP들이 하는 건 드래프트 파일
(`draft_content.json`)을 써 주는 것까지고, mp4로 빼는 건 사람이 CapCut을 열어서 해야 한다.
그래서 "기본은 Remotion, 필요할 때만 CapCut"으로 정했다.

`capcut-mcp`(JmsLdrn)를 `~/.claude/mcp-servers/`에 설치하고 user 스코프로 등록했다.
직접 의존성은 공식 MCP SDK와 zod 둘뿐이고 postinstall 스크립트가 없다. **CapCut 본체는 아직
설치돼 있지 않다** — MCP는 `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft`를
보는데 그 폴더가 없다.
