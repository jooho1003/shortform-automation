# B 트랙 채널 운영 전략

작성일: 2026-09-08  
상태: 승인됨

## 1. 핵심 결정

B 트랙은 초반에 하나의 예능을 주력으로 성장시키되, 채널 정체성을 특정 작품이나 프로그램명이 아니라 **같은 감정을 반복해서 전달하는 숏폼 포맷**으로 구축한다.

채널이 시청자에게 주는 약속은 다음과 같다.

> 연예인의 예상 못 한 진짜 반응과 관계성을 짧고 강하게 보여준다.

프로그램이 바뀌어도 웃음, 당황, 반전, 공감처럼 시청자가 기대하는 감정과 편집 리듬은 유지한다.

## 2. 초기 콘텐츠 구성

첫 30~50편은 다음 비율로 운영한다.

| 구분 | 비율 | 역할 |
|---|---:|---|
| 주력 예능 | 70% | 채널의 초기 시청자와 반복 포맷을 만든다. |
| 인접 예능 | 20% | 같은 출연자, 관계성 또는 같은 감정을 주는 소재로 확장한다. |
| 확장 실험 | 10% | 영화·드라마 등 다음 소재군의 가능성을 확인한다. |

작품이 아니라 시청자 감정을 기준으로 소재를 묶는다. 예를 들어 주력 소재가 특정 출연자의 당황스러운 순간이라면, 인접 소재도 다른 프로그램의 같은 출연자나 비슷한 관계성 장면을 선택한다.

## 3. 포맷 규칙

- 기본 권장 길이: `화이트 피드 카드`와 `블랙 피드 카드`는 15~30초. 해설 중심의 `브리핑 포커스`는 예외적으로 35~60초
- 첫 1~2초: 결과나 감정이 드러나는 제목 훅
- 본문: 원본 대사와 표정을 중심으로 전개
- 자막: 대사를 그대로 옮기기보다 핵심 단어와 감정만 강조
- 댓글 밴드: 두 피드 카드 템플릿은 첫 댓글을 0초부터 표시하고 이후 댓글을 지정 시각에 교체한다. `브리핑 포커스`는 각 댓글을 지정 시각에 처음 노출한다.
- 전환: 하드컷 중심, 불필요한 효과는 쓰지 않음
- 엔딩: 설명보다 반응, 표정 또는 반전이 끝나는 지점에서 종료

템플릿은 다음 기준으로 고른다.

| 상황 | 템플릿 |
|---|---|
| 가볍고 웃긴 예능, 호감·공감 | `화이트 피드 카드` |
| 갈등, 반전, 긴장, 충격 | `블랙 피드 카드` |
| 해설과 정보 전달이 중심인 예외 콘텐츠 | `브리핑 포커스` |

## 4. TTS 운영 원칙

TTS는 B 트랙의 기본 요소가 아니다. 원본 대사와 현장음을 우선하고, TTS가 없어도 상황이 이해되면 사용하지 않는다.

TTS는 다음 경우에만 사용한다.

1. 원본 대사만으로 상황의 앞뒤가 이해되지 않을 때
2. 무음 장면에 한 문장의 맥락 설명이 필요할 때
3. 사실 확인이나 비평 관점을 짧게 덧붙여야 할 때

한 영상에서 TTS는 최대 두 문장 또는 전체 길이의 20% 이내를 권장한다. 필요할 때는 Fish Audio 쇼츠톤을 우선 후보로 쓰고 Edge Hyunsu를 대체 수단으로 둔다. Fish API 키는 저장소에 저장하지 않고 환경변수 `FISH_API_KEY`로만 전달한다.

## 5. 오디오 후처리

정규화는 노이즈 제거를 대신하지 않는다. 처리 순서는 다음과 같다.

1. 원음에 노이즈가 실제로 들릴 때만 가벼운 노이즈 감소 적용
2. 대사와 선택적 TTS의 음량 균형 조정
3. 최종 음성 중심 믹스를 통합 음량 약 `-16 LUFS`, 최대 피크 `-1 dBTP` 기준으로 정규화
4. BGM은 대사가 나올 때 자동으로 낮춤

과도한 노이즈 제거로 목소리가 금속성으로 변하면 원음을 유지한다. Fish Audio 비교 샘플은 평가 자료로 보관하되, TTS 사용이 적으므로 특정 유료 음성 서비스에 운영을 종속시키지 않는다.

## 6. 확장 판단

인접 소재를 최소 5편 올린 뒤 다음 조건을 만족하면 비중을 늘린다.

- 게시 7일 후 조회수 중앙값이 주력 소재의 70% 이상
- 평균 시청 비율 차이가 주력 소재 대비 5%p 이내
- `Viewed vs Swiped away`가 주력 소재와 비슷함
- 인접 소재 게시 후 재방문 시청자가 감소하지 않음

위 기준은 플랫폼 공식 합격선이 아니라 내부 운영 기준이다. 10편, 30편, 50편 시점에 소재군별 성과를 다시 비교한다.

## 7. 권리와 수익화 원칙

방송·영화·드라마 원음을 사용하는 만큼 TTS 유무와 별개로 저작권 및 재사용 콘텐츠 위험이 있다. 단순 장면 재업로드가 되지 않도록 제목, 장면 선택, 맥락 구성, 자막, 비평 또는 해석에서 채널 고유의 가치를 분명히 만든다. 출처 표기는 허락을 대신하지 않으며, 차단·수익 귀속·삭제 요청 가능성을 운영 위험으로 관리한다.

## 8. 구현 반영 항목

현재 파이프라인은 문장별 TTS 길이를 기준으로 카드 템플릿의 15~30초를 검사한다. B 트랙 운영 전 다음 변경이 필요하다.

- TTS를 선택 입력으로 변경
- 카드 길이 검사를 TTS 합계가 아닌 최종 편집 타임라인 기준으로 변경
- 원본 오디오 유지 및 BGM 덕킹 지원
- 선택적 노이즈 감소와 최종 음량 정규화 추가
- TTS가 없을 때도 자막·댓글·렌더 단계가 정상 동작하도록 테스트
