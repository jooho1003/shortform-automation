# 네이버 블로그 자동화 구현 검증

작성일: 2026-09-18

## 검증한 사용자 흐름

사용자가 `/blog`에서 키워드로 글을 만들고, 원고를 편집·점검·승인한 뒤 서식 있는 copy 패키지를 받아 네이버 에디터에 사람이 붙여넣을 수 있다.

| 계층 | 확인 결과 |
|---|---|
| 브라우저 | 한글 키워드 글 생성, URL 인코딩된 상세 경로 진입, 본문 편집, 실시간 iframe 미리보기, 점검 결과, 원고 승인, copy 완료 메시지 확인 |
| API | `POST /api/blog`, `PUT/GET /api/blog/[id]`, `POST .../run`, `.../gate`, `.../package` 성공. 다른 origin과 비 JSON 잡 요청 거부 |
| 파일 SSOT | `프로젝트.json` revision 증가, `본문.md`, `점검.json`, 승인 sha256, `게시패키지/{본문.html,본문.txt,태그.txt}` 생성 확인 |
| Python | 키 없는 `manual-fallback` 키워드 보드, inspect 상태 병합, CLI 회귀, HMAC·승인 무효화·멱등·confirmed·셀렉터 사전 점검 테스트 통과 |
| 이미지 | `BlogThumb` Remotion Still을 실제 JPEG로 렌더하고 한글 줄바꿈·레이아웃을 육안 확인 |
| 빌드 | 웹 TypeScript 검사와 Next.js 프로덕션 빌드 성공. 기존 Turbopack 동적 파일 추적 경고 외 신규 오류 없음 |

## 자동 검증 명령

```powershell
cd pipeline
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q shortform tests
npm run typecheck -w web
npm run build -w web
npx tsc --noEmit -p remotion/tsconfig.json
```

## 외부 계정 경계

자동 발행은 구현하지 않았다. `draft` 코드는 준비됐지만 `draft_enabled: false`이고 에디터 셀렉터도 비어 있어 외부 계정에 아무 동작도 하지 않는다. 계정 주인이 별도로 승인하면 화면에 보이는 전용 Chrome에서 비공개 임시저장 1건만 실측하고, copy 패키지의 네이버 붙여넣기 서식 보존도 함께 확인한다.
