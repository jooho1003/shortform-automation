## Act에서 수정한 문제

- 기존 편집기의 6개 말풍선·200자·장면 1,000자 제한을 넘으면 승인 단계에서 알려 주도록 했다. 조용한 잘림 방지.
- 문서에서 가져온 표지의 두 번째 줄과 작은 표기를 분리해 부제가 유실되지 않게 했다.
- ‘담이 메시지’는 담이로 정규화하고, 이어지는 인용 대사는 같은 화자로 전달했다.
- 승인된 프로젝트의 상태를 scripted로 기록했다.
- 작업실 내부의 중첩 main을 section으로 변경했다.
- 모바일에서 기존 전역 사이드바가 작업실을 압축하지 않도록 이 화면에만 반응형 규칙을 적용했다.

## 범위 점검

계획에 없는 이미지 생성·인스타 게시·범용 시리즈 관리 기능은 추가하지 않았다. 기존 블로그·영상 작업 변경은 수정하지 않았다.
검증용 승인 프로젝트는 확인 후 제거했고, 1화는 최초 원고로 복원해 검토 전 상태로 남겼다. 생성한 2화도 검토 전 초안이다. 생성·수정 이력은 남아 있다.

## 한계

Codex 선택지는 기존 어댑터에 연결했지만 이번 실호출 검증은 Claude로 수행했다. 이미지 생성과 실제 게시까지 완료한 상태가 아니다. 최종 컷 구도와 말풍선 위치는 기존 컷 편집기에서 조정한다.
