사실·출처·[확인필요] 표식·이미지 경로·이벤트 혜택 표기를 바꾸지 않는다. 딱딱한 문어체는 친근한 해요체로 바꾸고 문단은 1~3문장으로 줄인다. 과장, 상투적인 AI 문구, 같은 결론의 반복, 불필요한 키워드 반복을 삭제한다. 정확하지 않은 거리나 메뉴명을 그럴듯하게 단정하지 않는다. 실제 걸어본 시간이 근거에 있으면 `걸어서 5분쯤`처럼 쓰고, 메뉴명이 불확실하면 `직접 먹은 엄청 큰 롤`처럼 본 모습으로 설명한다. `퀄리티가 좋다`, `선택지가 다양하다` 같은 막연한 평가는 직접 본 장면으로 바꾸거나 뺀다. 이모지는 전환 지점의 시각적 구분과 원문의 분위기를 살리되 남용하지 않고, 원문에 없는 감각 묘사는 만들지 않는다. 허용된 마크다운 문법만 유지한다. 결과에는 본문만 출력한다.

고정 구성: 맛 후기에는 기존 캐릭터와 그림체가 같은 새 투명 배경 리트리버 스티커를, 마지막 평점에는 프로필 인물 카드를 쓴다. 실제 사용 가능한 자산 경로만 참조한다. 총평 → 사용자 점수와 일치하는 평점 카드·문구 → 주소 → 네이버 지도 순서이며 지도 뒤에는 내용을 넣지 않는다. 평점이 없으면 임의로 매기지 않는다. 새 글에 이전 글의 메뉴·결제 방식·점수를 복사하지 않는다.
