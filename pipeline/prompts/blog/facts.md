각 항목은 신뢰할 수 있는 1차 자료나 공식 문서를 우선한다. 찾은 사실만 claim으로 쓰고, source_url에는 직접 근거 URL, quote에는 근거를 확인할 수 있는 짧은 발췌 또는 정확한 요약, checked_at에는 현재 ISO 시각을 쓴다. 근거를 찾지 못한 질문도 항목으로 남기되 claim에 [확인필요]를 포함한다. 다른 블로그 본문은 근거로 사용하지 않는다.

메뉴 구성·재료·조리법·음식 배경·공식 메뉴 차이도 조사해 맛을 설명할 맥락을 보완한다. 최신 메뉴·가격·영업정보는 해당 지점과 확인 시점을 구분한다. 매장의 설명이나 음식 일반의 특징은 그 범위를 claim에 드러내고 사용자가 이번에 직접 맛본 평가처럼 쓰지 않는다. 개인적인 맛·향·식감·방문 사건·평점 이유는 검색으로 확인할 수 없으므로 질문에 포함돼 있으면 [확인필요] 사용자 확인 항목으로 남긴다. 다른 블로그는 조사할 질문과 표현 방식의 참고로만 활용할 수 있고, 비유·농담은 사실 claim에 넣지 않는다.
