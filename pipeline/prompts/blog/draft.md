다음 개요와 검증된 근거로 네이버 블로그용 새 글을 작성한다.

문체 참고의 goodday_tomorrow 구성·서식 기준을 따른다. 요약 인용은 도입과 중복되지 않을 때만 2~3줄로 쓰고, 소제목·짧은 문단·빈 줄로 사진과 설명을 나눈다. 굵게는 짧은 핵심 구절에만 쓴다. 폰트·형광펜·정렬·네이버 구분선은 편집 단계에서 적용하므로 본문에 색상 코드, HTML/CSS, [형광펜] 같은 편집 지시문을 출력하지 않는다.

블로그 주제: {{niche}}
말투: {{persona}}
문체 참고:
{{style}}
주 키워드: {{keyword}}
권장 길이: {{length}}
개요: {{outline}}
근거: {{facts}}
광고 표기 유형: {{disclosure}}

허용 문법은 ##, ###, 문단, **굵게**, 목록, 인용, 표, 이미지 마크다운, 링크, 큰 주제 전환용 `---` 구분선뿐이다. H1, HTML, 코드 펜스는 쓰지 않는다. 친근한 1인칭 해요체로, 첫 문단에서 방문 시간·계기와 핵심 감상을 바로 말한다. 문단은 1~3문장으로 짧게 쓰고 사진마다 직접 본 것 또는 먹은 것을 한두 문장으로 설명한다. 이모지는 도입·소제목·맛 후기·평점 등 전환 지점에 자연스럽게 넣고 문장마다 반복하지 않는다. 장황한 인사·메타 설명·같은 감상의 반복·억지 길이 채우기는 피한다. 방문·주문·맛·가격·서비스에 관한 경험은 사용자가 직접 적은 내용이 있을 때만 쓴다. 없는 경험이나 사진을 지어내지 말고 [확인필요]를 남긴다. 수치·영업시간은 제공된 근거 안에서만 단정한다. 광고·협찬·제휴가 없더라도 리뷰 이벤트 혜택을 받았다면 짧고 분명하게 밝힌다. 글 맨 끝에는 근거로 확인한 해당 지점 주소와 네이버 지도 장소 링크를 둔다. 확인되지 않았다면 다른 지도를 대신 연결하지 말고 [확인필요]를 남긴다. 상위 글의 문장을 재사용하지 않는다. 제목은 본문에 넣지 않는다.

고정 구성: 맛 후기에는 캐릭터 그림체를 유지하되 이번 음식에 맞게 새로 만든 투명 배경 리트리버 스티커를, 마지막 평점에는 프로필 인물 카드를 쓴다. 실제 사용 가능한 자산 경로만 참조한다. 총평 → 사용자 점수와 일치하는 평점 카드·문구 → 주소 → 네이버 지도 순서이며 지도 뒤에는 내용을 넣지 않는다. 평점이 없으면 임의로 매기지 않는다. 새 글에 이전 글의 메뉴·결제 방식·점수를 복사하지 않는다.
