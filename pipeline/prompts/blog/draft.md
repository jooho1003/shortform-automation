다음 개요와 검증된 근거로 네이버 블로그용 새 글을 작성한다.

개인성·독창성: 이번 방문의 기억에 남는 선택·취향·작은 사건을 중심으로 쓴다. 사용자 별칭과 생활감 있는 어휘를 살리고, 비유·의인화·짧은 농담·소제목·문장 연결의 창작을 허용한다. 입력의 의미가 유지되게 짧은 맛 메모를 생생하게 풀되 새로운 동행·대화·주문·대기·서비스·향·식감·재방문 사건을 체험처럼 추가하지 않는다.

맛과 판단: 확인된 식감·온도·맛의 강도·향·먹고 난 뒤 남는 맛·양·조합 중 특징을 골라 무엇이 내 입맛에 맞고 무엇을 더 선호했는지 연결한다. 실제로 확인된 먹는 순서와 조합의 변화도 살린다. 메뉴마다 감각·비교를 채우지 않는다. 검색한 메뉴·재료·조리법·음식 배경은 `매장 설명에 따르면…`처럼 출처와 근거 링크를 드러내고 음식 일반의 설명과 이번 접시의 체험을 구분한다. 추론은 `설명만 보면…`, `…일 듯해요`처럼 예상임을 밝히며 타인의 맛 평가를 내 체험으로 쓰지 않는다.

마무리 점검: 가게 이름만 바꾸면 재사용되는 무난한 평가와 요약·도입·메뉴·총평의 같은 감상 반복을 줄인다. 사용자 평점이 있으면 이유를 총평에 연결하고, 이유가 없으면 [확인필요]로 남긴다. 점수에 맞춰 단점을 창작하지 않는다. 필요한 핵심 맛·평점 이유만 사용자 확인 대상으로 남기고 기존 개인적인 표현을 보존한다.

문체 참고의 goodday_tomorrow 구성·서식 기준을 따른다. 본문 맨 위에 `|` 모양의 왼쪽 세로선 요약 인용 2~3줄을 반드시 `>` 문법으로 쓰고, 짧은 글에서도 생략하지 않는다. 요약과 겹치는 도입 문장을 다듬고, 소제목·짧은 문단·빈 줄로 사진과 설명을 나눈다. 굵게는 짧은 핵심 구절에만 쓴다. 폰트·형광펜·정렬·네이버 구분선은 편집 단계에서 적용하므로 본문에 색상 코드, HTML/CSS, [형광펜] 같은 편집 지시문을 출력하지 않는다.

블로그 주제: {{niche}}
말투: {{persona}}
문체 참고:
{{style}}
주 키워드: {{keyword}}
권장 길이: {{length}}
개요: {{outline}}
근거: {{facts}}
광고 표기 유형: {{disclosure}}

허용 문법은 ##, ###, 문단, **굵게**, 목록, 인용, 표, 이미지 마크다운, 링크, 큰 주제 전환용 `---` 구분선뿐이다. H1, HTML, 코드 펜스는 쓰지 않는다. 친근한 1인칭 해요체로, 첫 문단에서 방문 시간·계기와 핵심 감상을 바로 말한다. 문단은 1~3문장으로 짧게 쓰고 사진마다 직접 본 것 또는 먹은 것을 한두 문장으로 설명한다. 이모지는 도입·소제목·맛 후기·평점 등 전환 지점에 자연스럽게 넣고 문장마다 반복하지 않는다. 장황한 인사·메타 설명·같은 감상의 반복·억지 길이 채우기는 피한다. 방문·주문·맛·가격·서비스에 관한 경험은 사용자가 직접 적은 내용이 있을 때만 쓴다. 없는 경험이나 사진을 지어내지 말고 [확인필요]를 남긴다. 수치·영업시간은 제공된 근거 안에서만 단정한다. 광고·협찬·제휴가 없더라도 리뷰 이벤트 혜택을 받았다면 짧고 분명하게 밝힌다. 글 맨 끝에는 근거로 확인한 해당 지점 주소와 네이버 지도 장소 링크를 둔다. 확인되지 않았다면 다른 지도를 대신 연결하지 말고 [확인필요]를 남긴다. 상위 글의 문장을 재사용하지 않는다. 제목은 본문에 넣지 않는다.

고정 구성: 리트리버는 사진 없이 글만 이어지는 구간의 전환에만 쓰며, 실제 사진 바로 앞뒤에 붙이지 않는다. 사진과 스티커 사이에는 내용이 있는 본문 문단을 두고, 빈 줄·소제목·구분선만으로 분리하지 않는다. 맛 후기 시작에 고정 배치하지 않는다. 사용할 때는 캐릭터 그림체를 유지하되 이번 음식에 맞게 새로 만든 투명 배경 스티커를 쓴다. 마지막 평점에는 프로필 인물 카드를 쓴다. 실제 사용 가능한 자산 경로만 참조한다. 총평 → 사용자 점수와 일치하는 평점 카드·문구 → 주소 → 네이버 지도 순서이며 지도 뒤에는 내용을 넣지 않는다. 평점이 없으면 임의로 매기지 않는다. 새 글에 이전 글의 메뉴·결제 방식·점수를 복사하지 않는다.
