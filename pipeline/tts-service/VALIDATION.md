- 두 번째 샘플 재생 시 첫 번째 샘플이 정지하는 것을 확인.

- 새 프리셋은 고정된 참조 WAV·실제 발화 대본·해시를 가짐. 기존 샘플의 속도 후처리본 대신 원본 WAV가 참조로 저장됨.
- 390×844 화면에서 페이지 가로 넘침 없음. 데스크톱에서는 입력·비교 영역을 두 열로 표시.

- 엔진 종료 시 재연결 안내가 나타나고 ‘엔진 시작’으로 최신 코드의 서비스를 다시 실행하는 것을 확인. 저장된 음성과 프리셋을 유지함.

## 실제 제작 경로 통합 검사

`smoke_episode.py c064d835e21b4c57bffa40540fa10855`를 실행했다. 테스트용 짧은 검은 클립과 동일한 두 문장을 임시 B안 회차에 넣어 실제 서비스 → Python 어댑터 → WAV → FFmpeg 연결 → 타임라인·manifest 저장을 수행했다.

- B안 문장 WAV가 웹 샘플 WAV와 바이트 단위로 일치.
- 타임라인: **9.132초**, 내레이션 실측: **9.131833초**.
- 두 문장과 문장 간격 반영, 두 개 문장 manifest 기록 확인.
- 성공 후 이전 소재 백업과 render/upload 무효화 확인.
- 테스트 회차는 정리했고 실제 사용자 회차나 외부 API는 변경하지 않음.
- 짧은 연결 검사용 대본이므로 브리핑의 권장 35–60초 범위 경고가 출력됨. 이 검사는 완성 영상의 편집 품질을 평가하지 않음.

## 수정한 실제 환경 문제

- `sox` Python 패키지가 numpy 설치 전 메타데이터 생성에 실패해 설치 순서를 문서화.
- Windows에서 Hugging Face의 동시 다운로드 중 심볼릭 링크 지원 검사 경합으로 WinError 1314 발생. Windows 다운로드를 직렬화해 일반 사용자 권한의 파일 복사 방식으로 완료.
- 실행 중 엔진을 다시 시작하려는 요청이 기존 작업 파일을 ‘중단됨’으로 덮어쓸 수 있어 앱·큐 생성 전 OS 파일 잠금을 추가.
- 스튜디오 WAV를 본편에 복사할 때 재차 속도 필터를 통과하지 않도록 수정해 원본 청취 파일과 동일하게 유지.

## 남은 범위

실시간 스트리밍, 강제 자막 정렬, 자동 캐시 정리, 화면을 닫은 뒤 비교 고정 복원, C안 연결은 포함하지 않았다. 모델을 바꾸면 GPU에서 이전 모델을 내리고 다음 모델을 로딩하므로 준비 시간이 추가된다. 대사 길이와 문장별 음색은 사용할 대본으로 최종 청취해야 한다.
